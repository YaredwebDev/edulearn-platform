2.3 Theorems on Polynomials

Polynomial Division Theorem (Thm 2.1)

If f(x) and d(x) are polynomials with d(x)≠0 and deg d ≤ deg f, then there exist unique polynomials q(x) and r(x) such that

f(x) = d(x)q(x) + r(x)

where r(x)=0 or deg r < deg d. If r(x)=0, d(x) divides f(x) exactly.

Remainder Theorem (Thm 2.2)

Let f(x) be a polynomial of degree ≥1 and c any real number. If f(x) is divided by (x−c), the remainder is f(c).

  • The value of f at c equals the remainder when dividing by x−c.
  • Proof: f(x)=(x−c)q(x)+k, substitute x=c → f(c)=k.

Example: f(x)=x³−3x²+4, divide by x−1 → remainder f(1)=1−3+4=2.

Example: f(x)=2x³+5x²+3x+2, divide by x+1 (=x−(−1)) → c=−1 → remainder f(−1)=−2+5−3+2=2.

Example: 3x³−4x²+bx−5 divided by x−2 has remainder 10 → f(2)=24−16+2b−5=3+2b=10 → b=7/2... (check: the textbook gives b=7). Always set f(c)=given remainder and solve for the unknown.

✍️ Must-know: ✍️ Must-know: For divisor (ax+b), write it as a(x−(−b/a)); the remainder is f(−b/a).

Factor Theorem (Thm 2.3)

Let f(x) be a polynomial of degree ≥1 and c any real number. Then:

  1. If f(c)=0, then (x−c) is a factor of f(x).
  2. If (x−c) is a factor of f(x), then f(c)=0.

Example: x+2 is a factor of x²+5x+6 because f(−2)=(−2)²+5(−2)+6=0.

Example: f(x)=x⁴−x³−x²−x−2: f(−1)=0 (x+1 factor), f(2)=0 (x−2 factor), but f(−2)=20≠0 (x+2 not a factor).

✍️ Must-know: ✍️ Must-know: Factor theorem is the reverse of remainder theorem: remainder 0 ⟺ (x−c) is a factor.
