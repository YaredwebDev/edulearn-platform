3.2 Systems of Linear Equations in Two Variables

◌ Not started

Definition: A linear equation in two variables: ax + by = c (a≠0, b≠0). Its graph is a straight line; it has infinitely many solutions (all points on the line).

A system of two linear equations in two variables can have: - One solution (lines intersect) — independent system, a₁/a₂ ≠ b₁/b₂. - No solution (lines parallel) — inconsistent, a₁/a₂ = b₁/b₂ ≠ c₁/c₂. - Infinitely many (lines coincide) — dependent, a₁/a₂ = b₁/b₂ = c₁/c₂.

3.2.1 Solving using tables

Solve each equation for y, make a table of x and y, find the pair satisfying both.

Example: {2x + y = 15; 3x − y = 5} → y = −2x + 15 and y = 3x − 5. The ordered pair (4, 7) satisfies both.

3.2.2 Substitution method

  1. Solve one equation for one variable.
  2. Substitute into the other equation.
  3. Solve for the second variable.
  4. Substitute back for the first.
  5. Check.

Example: {−x + y = −5; 2x − 5y = 1}. From first, y = x − 5. Substitute: 2x − 5(x−5) = 1 → −3x + 25 = 1 → x = 8. Then y = 3. Solution: (8, 3).

3.2.3 Elimination (addition) method

Eliminate one variable by adding equations whose coefficients are opposites; multiply by a constant first if needed.

Example 1: {x + 2y = 1; −x + y = 5}. Adding: 3y = 6 → y = 2. Then x = −3. Solution: (−3, 2).

Example 2: {4x + 2y = 28; x + 2y = 13}. Subtract (or add after multiplying second by −1): 3x = 15 → x = 5, then y = 4. Solution: (5, 4).

Example 3: {3x + 4y = 2; x − 2y = 4}. Multiply second by −3: {3x+4y=2; −3x+6y=−12}. Add: 10y = −10 → y = −1, then x = 2. Solution: (2, −1).

Word problem: Three pens + two books = Birr 118; one pen + two books = Birr 106. Let p = pen, b = book. {3p+2b=118; p+2b=106}. From second p = 106 − 2b. Substitute: 3(106−2b)+2b=118 → 318−6b+2b=118 → −4b=−200 → b=50, p=6. So a pen is Birr 6, a book Birr 50.

3.2.4 Graphical method

  1. Graph the first equation.
  2. Graph the second on the same axes.
  3. Determine whether lines intersect, are parallel, or coincide.
  4. The intersection point is the solution.

Example 1: {2x + y = −8; x − y = −1} → y = −2x−8 and y = x+1. Lines intersect at (−3, −2).

Example 2: {2x − y = −1; 4x − 2y = −8} → y = 2x+1 and y = 2x+4. Parallel → no solution.

Example 3: {3x + y = 6; 6x + 2y = 12} → both give y = −3x+6 → coincident → infinite solutions.

✍️ Must-know — classify systems by ratios: - a₁/a₂ = b₁/b₂ = c₁/c₂ → infinite solutions (dependent/coincident). - a₁/a₂ = b₁/b₂ ≠ c₁/c₂ → no solution (inconsistent/parallel). - a₁/a₂ ≠ b₁/b₂ → one solution (independent/intersect).
