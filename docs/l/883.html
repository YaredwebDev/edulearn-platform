1.3 The Scientific Method

Biology is a science of inquiry. Scientists come up with new theories to explain new findings using the scientific method.

Steps of the scientific method:

  1. Observation — careful observation (often of a problem) leads to a question. Can be direct (sense organs) or indirect (tools like microscopes).
  2. Asking questions — observations lead the scientist to ask questions (inquiry).
  3. Forming a hypothesis — a hypothesis is a proposed scientific explanation (possible answer) for a set of questions. Several hypotheses can be proposed; scientific hypotheses must be testable.
  4. Testing the hypothesis — through experimentation. An experiment must be duplicable so other scientists can repeat it and get similar results. If not supported, propose a new hypothesis.
  5. Making conclusions — scientists ask whether their original hypothesis could still be right in light of new information; if not, they reject it and try alternate explanations.
  6. Communicating the findings — scientists write a paper explaining what they did and the results, and submit it to a scientific journal.
✍️ Must-know: Hypothesis = a proposed, testable scientific explanation. The correct order of the scientific method: Observation → Question → Hypothesis → Experiment → Conclusion/Results → Communication.

Example: A torch (hand lamp) that won't work → observe, ask why, propose hypotheses (batteries dead? bulb broken?), test, conclude.

Note: Activity example — seed germination: Germinate bean seeds at different temperatures (room, cold, hot), measure germination times and seedling lengths, draw a bar graph (X axis = time/day of germination; Y axis = length), interpret, conclude, and report.
