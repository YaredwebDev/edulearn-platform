9.2 Vocabulary of the Unit ("language words")

◌ Not started
Word Meaning
mother-tongue / first language the language first learned at home
multiple languages many languages
diversity variety
bilingual / bilingualism speaking two languages
polyglot a person who speaks many languages
multilingual / multilingualism speaking more than one (esp. many) language
plurilingual speaking/being able to use several languages
communication sharing information/messages
multicultural / multiculturalism having many cultures
monolingual speaking only one language
cognitive relating to thinking/mental processes
executive control the brain's system for attention & working memory
inhibition the ability to ignore irrelevant stimuli
dementia / Alzheimer's brain diseases causing memory loss
innate inborn, natural

✍️ Must-know: Definitions to distinguish: monolingual (1 language), bilingual (2), multilingual (>1/many), polyglot (many languages). Know the synonyms: mother-tongue = native/first language; "permits" = allows.
