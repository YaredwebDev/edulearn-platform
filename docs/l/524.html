10.5 Data Table / Graph Reading

◌ Not started

The unit shows the social media status of Ethiopia in 2021 (as a percentage):

Social media %
Twitter 39.38
Facebook 37.34
YouTube 10.74

The same data drawn as a bar graph for easier reading:

How to read/answer: 1. Read the title and the labels (platforms, %). 2. Identify the highest (Twitter ~39%) and lowest (YouTube ~11%) values. 3. Comment on the spread: Twitter and Facebook dominate, YouTube trails. 4. Discuss what social media should do to benefit Ethiopians and how internet use can be improved (speaking/discussion questions in the unit).

✍️ Must-know: Learn the platforms and their percentages so you can interpret the graph in an exam and discuss Ethiopia's social-media landscape.
