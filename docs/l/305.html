5.11 🧮 Key Equations to Memorise

◌ Not started
  • KC = ([C]ᶜ[D]ᵈ)/([A]ᵃ[B]ᵇ) [homogeneous, molarities]
  • KP = (P_CᶜP_Dᵈ)/(P_AᵃP_Bᵇ) [gases, partial pressures]
  • KP = KC(RT)^Δn, Δn = (c+d) − (a+b) for gases; KP = KC when Δn = 0
  • Q has the same form as K but uses current (non-equilibrium) concentrations
  • Direction: Q = K (equilibrium), Q < K (→ forward), Q > K (← reverse)
  • Extent: KC/KP > 10¹⁰ → essentially complete; < 10⁻¹⁰ → essentially no reaction
  • K_overall = K₁ × K₂ × K₃…; reverse reaction → 1/K; multiply eqn by ½ → K^½

✅ End-of-unit self-check: Can you (1) distinguish reversible/irreversible and define dynamic equilibrium with its characteristics; (2) write KC and KP for any reaction and omit pure solids/liquids correctly; (3) compute KC/KP values and units; (4) use KP = KC(RT)^Δn and decide when they are equal; (5) combine step constants (multiply, reverse, exponentiate); (6) predict extent from K and direction from Q; (7) set up and solve equilibrium-concentration ICE-style problems (including quadratics and discarding impossible x); (8) apply Le Chatelier to concentration, pressure/volume, temperature and catalyst changes; and (9) explain the optimum conditions (and why) for the Haber and Contact processes?
