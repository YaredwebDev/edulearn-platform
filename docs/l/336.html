  1. Modern periodic law: properties are a periodic function of atomic number (Moseley). Mendeleev used atomic weight.
  2. Modern table: 7 periods, 18 groups.
  3. Group IA = alkali metals; IIA = alkaline earth metals; VIIA = halogens; VIIIA = noble gases.
  4. Period number = number of shells; group number (A) = valence electrons.
  5. Atomic radius: increases down, decreases across (left→right).
  6. Ionization energy: increases across, decreases down. Cs = lowest, F = highest.
  7. Electron affinity: energy released adding electron (negative). F < Cl (small-size repulsion).
  8. Electronegativity: F = 4.0 (highest); Cs = 0.7 (lowest); increases across, decreases down.
  9. Blocks: last electron in s/p/d/f determines s-, p-, d-, f-block.
  10. Diagonal relationship: period-2 element resembles next group's period-3 element (e.g., Li ~ Mg).
