6.3 Measures of Each Interior and Exterior Angle of a Regular Polygon

◌ Not started

Definition: A polygon is regular if it is equiangular (equal angles) and equilateral (equal sides). E.g., equilateral triangles, squares, regular hexagons (honeycomb).

For a regular n-gon: - Each interior angle = (n−2)×180° / n. - Each exterior angle = 360° / n. - Interior + exterior at each vertex = 180°.

Example — regular pentagon (n = 5): - Each interior angle = 3×180°/5 = 108°. - Each exterior angle = 360°/5 = 72°.

✍️ Must-know: Interior = (n−2)×180°/n; exterior = 360°/n. They sum to 180°.
