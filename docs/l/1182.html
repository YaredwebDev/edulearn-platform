📌 QUICK REVISION / MUST-KNOW BOX (Unit 1)

  • Set = well-defined collection of objects.
  • Describe sets by: verbal, roster (complete/partial listing), set-builder.
  • Empty set ∅; finite vs infinite; equal vs equivalent; universal set.
  • Subset ⊆, proper subset ⊂; number of subsets = 2ⁿ, proper = 2ⁿ−1.
  • Union ∪, intersection ∩, complement ′, difference − , symmetric difference Δ, product ×.
  • De Morgan: (A∪B)′ = A′∩B′; (A∩B)′ = A′∪B′.
  • n(A∪B) = n(A) + n(B) − n(A∩B).
  • Venn diagrams are drawn as circles inside rectangle U.
