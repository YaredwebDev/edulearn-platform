📚 Unit 2 Summary (Key Facts)

◌ Not started
  • Position relative to a reference; distance is path length; displacement is straight-line change in position.
  • Average velocity = Δs/Δt; average speed = total distance/total time.
  • Instantaneous velocity = slope of tangent on s–t graph.
  • Acceleration = Δv/Δt; instantaneous = average for uniform motion.
  • Equations of motion: v = v₀+at; s = v₀t+½at²; v² = v₀²+2as; free fall uses g and h.
  • Graphs: s–t parabola, v–t straight line, a–t horizontal line.
  • Relative velocity: same direction = difference; opposite = sum.
