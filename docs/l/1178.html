1.2 Set Description

Sets can be described in three (or four) ways:

i) Verbal (statement) method — describe the elements in words.

  • Example: "The set of whole numbers greater than 1 and less than 20."

ii) Listing methods:

  • Complete listing (roster) method — list ALL elements in braces { }.
  • {2, 4, 6} = even positive integers less than 7.
  • {a, e, i, o, u} = vowels.
  • Partial listing method — list a few elements and use "…" when full listing is impossible.
  • {1, 2, 3, …, 99} = natural numbers less than 100.
  • 𝕎 = {0, 1, 2, 3, …} = whole numbers.

iii) Set-builder method (defining property) — {x : condition on x}.

  • A = {1, 2, …, 10} = {x : x ∈ ℕ and x < 11}.
  • B = {0, 2, 4, …} = {x : x ∈ ℤ and x is a non-negative even integer} = {2x : x ∈ 𝕎}.

Number sets you must know:

  • ℕ = {1, 2, 3, …} (natural numbers)
  • 𝕎 = {0, 1, 2, 3, …} (whole numbers)
  • ℤ = {…, −3, −2, −1, 0, 1, 2, 3, …} (integers)
✍️ Must-know: ✍️ Must-know: Know the three methods of describing a set (verbal, listing/roster, set-builder) and the symbols ℕ, 𝕎, ℤ.
