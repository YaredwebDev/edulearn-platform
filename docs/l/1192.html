3.4 Applications of Solving Equations

System application: Circus tickets Birr 25 (children) / Birr 50 (adults); 2,000 attendees, revenue Birr 70,000.

  • c + a = 2000; 25c + 50a = 70000.
  • a = 2000 − c → 25c + 50(2000−c) = 70000 → −25c = −30000 → c = 1200, a = 800.
  • Answer: 1,200 children and 800 adults.

Quadratic application: Object dropped from 600 m, h = 600 − 16t². Time to reach 200 m:

  • t = √((600−h)/4)... t² = (600−200)/16 = 25 → t = 5 seconds.

Projectile: h = −16t² + 48t + 64. Hits ground when h = 0: 0 = −16(t² − 3t − 4) = −16(t+1)(t−4) → t = 4 seconds (t = −1 rejected).

✍️ Must-know: ✍️ Must-know: In word problems, define variables, build the equation(s), solve, and reject impossible answers (negative time, etc.).
