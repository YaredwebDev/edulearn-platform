4.10 Voltmeter and Ammeter Connection

◌ Not started
  • Voltmeter: measures potential difference (voltage). Connected in parallel with the component. Has high resistance so it draws minimal current.
  • Ammeter: measures current. Connected in series in the circuit. Has low (nearly zero) resistance so it does not change the current.
  • Multimeter: a device that measures voltage, current, or resistance.

✍️ Must-know: Voltmeter → parallel (high resistance); ammeter → series (low resistance). Never connect an ammeter in parallel (it would draw most of the current and get damaged).
