5.6 Writing: Topic Sentence & Paragraph

  • Topic sentence carries the main idea of the paragraph; can be at the beginning, middle, or end — but put it first for beginners (it guides supporting details).
  • A good topic sentence draws the reader's attention to read on.
  • Example: "Haile Gebresillassie is one of Ethiopia's most famous long distance runners." — the rest of the paragraph supports this.
  • Practise writing a topic sentence then adding supporting details (e.g., for Adwa, disability, transport, Catherine Ndreba paragraphs).

📝 Writing focus

  • Describe a process (e.g., how honey is made, how "datt'a" is prepared, how Ethiopian coffee is made) using passive voice and sequence markers (first, having done this, the next step is, then, finally).
  • Write a clear topic sentence + supporting details.
Note: ✅ End-of-unit self-check: Can you (1) give the main idea of each honey paragraph, (2) define the vocabulary, (3) give clipped/blended words, (4) use get/give/go phrasal verbs, (5) convert active↔passive including with modals, (6) apply subject-verb agreement rules, (7) choose do vs make, (8) write a topic sentence, (9) describe a process in passive voice?
