9.2 Probability

◌ Not started

Definition: Probability is a numerical value that describes the likelihood of the occurrence of an event in an experiment.

Experimental probability is determined from data collected by repeating an experiment.

  • Experiment: a trial by which an observation is obtained but whose outcome cannot be predicted in advance.
  • Equally likely outcomes: each outcome occurs equally often when repeated many times.
  • Definition: If an experiment has n equally likely outcomes and m is a particular outcome, then probability = m/n.

Example (tossing a coin twice): possible outcomes HH, HT, TH, TT. - Probability of exactly one tail = 2/4 = 1/2 (HT, TH). - Probability of at least one head = 3/4 (HH, HT, TH).

Sample space and event

  • Sample space (S): the set of all possible outcomes of an experiment.
  • Event: a subset of the sample space.

Examples: - Toss one coin: S = {H, T}. - Throw one die: S = {1,2,3,4,5,6}. - Toss two coins: S = {HH, HT, TH, TT}.

Example (cards): Numbers 4 to 30 on cards, choose one at random. S = {4,5,…,30}. Events: "number divisible by 3" = {6,9,12,…,30}; "number even" = {4,6,8,…,30}.

Probability of an event

Definition: The theoretical probability of event E: P(E) = n(E)/n(S) = (favourable outcomes)/(total outcomes).

Example (die): P(odd) = P({1,3,5}) = 3/6 = 1/2.

Example (workers): 45 men, 55 women out of 100 → P(man) = 45/100 = 0.45.

Example (coin + die): tree diagram gives 12 outcomes. P(tail and odd) = 3/12 = 1/4. P(head and number ≤ 5) = 5/12.

Experimental vs theoretical: Toss a coin 10,000 times, get 5,010 heads. Tails = 4,990 → P(tails) = 4990/10000 = 0.499 (close to 1/2).

Tree diagrams

Used when many combined events are considered. Each branch shows a possible outcome and its probability.

Example (three coins): S = {HHH, HHT, HTH, HTT, THH, THT, TTH, TTT} (8 outcomes). - P(exactly two heads) = 3/8. - P(exactly one tail) = 3/8. - P(three tails) = 1/8. - P(at least two heads) = 4/8 = 1/2.

Example (coin + die): 2 × 6 = 12 outcomes. P(head and even) = 3/12 = 1/4.

✍️ Must-know: P(E) = n(E)/n(S). Sample space = all outcomes; event = subset. Use tree diagrams to count combined-outcome probabilities.
