4.5 Grammar: Conditionals

◌ Not started

4.5.1 The Zero Conditional (facts / general truths)

If + present, + present. - "If you heat ice, it melts." - "If it rains, the ground gets wet." Used for things that are always true / scientific facts.

4.5.2 The First Conditional (probable future)

If + present, + will/can/may + V1. - "If the park opens early, tourists will come." - "If you protect the forest, animals will survive." Used for likely/possible future situations.

✋ Trap: In the if-clause of a first conditional use the present, not "will": "If it rains, we will stay" — never "If it will rain."
