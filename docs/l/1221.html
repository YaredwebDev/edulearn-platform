📌 QUICK REVISION / MUST-KNOW BOX (Unit 8)

  • Scalar = magnitude only; vector = magnitude + direction.
  • Column vector (x, y); |ā| = √(x²+y²).
  • Equal vectors: same magnitude & direction. Opposite: −ā.
  • Parallel: one is a scalar multiple of the other.
  • Triangle law AB + BC = AC; Parallelogram law (diagonal = sum).
  • Subtract: a − b = a + (−b).
  • k(x,y) = (kx, ky); k>0 same direction, k<0 opposite.
  • Position vector = (x₂−x₁, y₂−y₁) = xi + yj.
