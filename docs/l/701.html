📚 Unit 5 Summary (Key Facts)

◌ Not started
  • Simple machine = device that makes doing mechanical work easier.
  • Machines are direction changers, force multipliers, or speed/distance multipliers.
  • Six types: inclined plane, wedge, screw, lever, wheel & axle, pulley.
  • Effort = force put in; load = force got out. Work input = effort × distance; work output = load × distance.
  • AMA = load/effort; V.R = distance by effort/distance by load; η = M.A/V.R.
  • If no energy losses, AMA = IMA = V.R.
  • Three classes of levers (position of fulcrum/load/effort).
  • Levers: V.R = d_E/d_L. Inclined plane: V.R = l/h. Wedge: V.R = l/t. Screw: M.A = πd/p. Wheel & axle: V.R = R/r. Pulley: V.R = N (number of rope sections).
