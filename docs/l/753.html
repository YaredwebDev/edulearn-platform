4.12 Electric Projects (Series & Parallel Circuits)

◌ Not started

Project 4.1 — Series lamp circuit: two lamps in series powered by AA batteries. Each lamp sees only half the total voltage (they are dim). If one lamp is removed, the circuit is broken and the other lamp goes out (series drawback).

Project 4.2 — Parallel lamp circuit: two lamps in parallel. Each lamp sees the full voltage (lights are brighter). If one lamp burns out, the other remains lit (parallel advantage).

Project 4.3 — Electric house project: wire a model house with separate series, parallel, and complex (combination) circuits, each switchable independently, with a labelled circuit diagram.

✍️ Must-know: In series, if one fails all fail (voltage divided). In parallel, each component works independently (full voltage).
