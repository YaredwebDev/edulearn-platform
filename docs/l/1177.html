1.1 Sets and Elements

A set is a collection of well-defined objects or elements. "Well-defined" means that given any object, we can decide whether it belongs to the set or not.

  • If a is an element of set A, we write a ∈ A ("a belongs to A").
  • If b is not an element of A, we write b ∉ A ("b does not belong to A").
  • Sets are usually named with capital letters (A, B, X, …); elements with small letters (a, b, x, …).

Examples:

  • The set of students in your class is a well-defined set (members are clearly known).
  • "The collection of kind students in your school" is not well-defined — it is hard to decide who is "kind."
  • If G = {vowel letters}, then a ∈ G, o ∈ G, but b ∉ G.
✍️ Must-know: ✍️ Must-know: A set must be well-defined — you must be able to tell whether any given object is in the set or not. Examples that are NOT well-defined: "beautiful girls," "hardworking teachers," "kind students."

Example: If A = set of positive even numbers {2, 4, 6, 8, …}, then 4 ∈ A, 5 ∉ A, −2 ∉ A, 0 ∉ A.
