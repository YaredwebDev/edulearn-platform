4.3 Inequalities Involving Absolute Value

◌ Not started

Rules (c > 0): - |k| < c → −c < k < c. - |k| ≤ c → −c ≤ k ≤ c. - |k| > c → k > c or k < −c. - |k| ≥ c → k ≥ c or k ≤ −c.

Examples: - |x| ≤ 1 → −1 ≤ x ≤ 1. - |x| > 1 → x < −1 or x > 1. - |x + 2| < 4 → −4 < x + 2 < 4 → −6 < x < 2 → interval (−6, 2). - |x + 2| ≥ 4 → x ≤ −6 or x ≥ 2 → (−∞, −6] ∪ [2, ∞). - |3x − 2| ≥ 7 → 3x − 2 ≥ 7 or 3x − 2 ≤ −7 → x ≥ 3 or x ≤ −5/3. - |−x + 4| < 0 → no solution (absolute value can't be negative). - |−5x − 7| ≤ 0 → equals zero: −5x − 7 = 0 → x = −7/5 (one solution). - |6x + | > −2 → all real numbers (absolute value always > a negative).

✍️ Must-know: |k| < c gives a "between" (compound) answer; |k| > c gives a "split" (union) answer. Watch ≤/≥ for closed intervals and open dots.
