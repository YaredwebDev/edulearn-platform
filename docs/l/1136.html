1.2 Functions

1.2.1 The notion of function

Definition (Function): A function f is a set of ordered pairs with the property that whenever (x,y) and (x,z) belong to f, then y=z. Equivalently: a relation in which no two distinct ordered pairs have the same first element.

  • Repeated first elements are allowed only if they map to the same second element. Example: {(1,5),(1,5),(3,−8),(3,−8),(7,4)} IS a function (duplicates removed).
  • R={(2,3),(5,3),(3,6),(7,6),(5,8)} is NOT a function because (5,3) and (5,8) share first element 5 but differ.

Domain, co-domain, range:

  • Domain = set of all input (x) values.
  • Co-domain = set of all possible outputs (B in f:A→B).
  • Range = set of actual outputs f(x) (a subset of the co-domain).

Notation: f(x) is the image of x; x is the pre-image of f(x). f:A→B means domain is A and range ⊆ B.

Examples:

  • f(x)=3x+4: domain ℝ, range ℝ (every real has a pre-image).
  • f(x)=√(x−2): domain {x≥2}, range {y≥0}.
  • f(x)=1−3x²: domain ℝ; f(2)=1−12=−11, f(−1)=1−3=−2.
✍️ Must-know: ✍️ Must-know: To find a domain: (i) denominators ≠ 0, (ii) expressions under even radicals ≥ 0. Evaluating f at a means substituting x=a into the formula.

1.2.2 Combination of functions

For two functions f and g with overlapping (intersecting) domains:

  • Sum: (f+g)(x) = f(x) + g(x)
  • Difference: (f−g)(x) = f(x) − g(x)
  • Product: (fg)(x) = f(x)·g(x)
  • Quotient: (f/g)(x) = f(x)/g(x), g(x)≠0

The domain of a combination = intersection of the domains of f and g; for the quotient, additionally exclude where g(x)=0.

Example: f(x)=x−5, g(x)=2x+1 → domain of f+g and f−g is ℝ (both domains are ℝ).

Example: f(x)=√x, g(x)=√(4−x²). Domain f=[0,∞), domain g=[−2,2]. Intersection = [0,2]. (f/g): g≠0 → [0,2). (g/f): f≠0 → (0,2].

✍️ Must-know: ✍️ Must-know: Domain of f/g = (domain f ∩ domain g) minus points where g(x)=0. Domain of fg = domain f ∩ domain g.

Vertical Line Test

A graph is the graph of a function if and only if no vertical line intersects the graph in more than one point. If a vertical line cuts a curve twice, the curve is NOT a function.

1.2.3 Types of functions

  • One-to-one (injective): each element of the domain has a distinct image. f:ℝ→ℝ, f(x)=3x+5 is one-to-one because f(x₁)=f(x₂) ⟹ 3x₁+5=3x₂+5 ⟹ x₁=x₂.
  • Onto (surjective): each element of the co-domain has at least one pre-image.
  • One-to-one correspondence (bijective): both injective and surjective.

Examples (fig. 1.19): (a) onto but not one-to-one; (b) both one-to-one and onto (bijective); (c) injective but not surjective; (d) neither injective nor surjective.

✍️ Must-know: ✍️ Must-know: Injective ⟺ distinct x give distinct y. Surjective ⟺ range = co-domain. Bijective = injective + surjective. f(x)=x² on ℝ→ℝ is neither injective nor surjective.

1.2.4 Graphs of functions

Graph of a function = set of all points {(x, f(x)) : x ∈ domain}.

Linear function: f(x)=ax+b, a≠0. Constant function: f(x)=b.

  • Graph is a straight line.
  • a>0 → increasing; a<0 → decreasing; a=0 → horizontal.
  • Slope = a, y-intercept (0,b), x-intercept (−b/a, 0).
Linear functions with different slopes through (0,2)
✍️ Must-know: ✍️ Must-know: In f(x)=ax+b, the coefficient a is the slope (steepness), b is the y-intercept. Bigger |a| → steeper line.

Quadratic function: f(x)=ax²+bx+c, a≠0. Graph is a parabola (U-shape).

  • If a>0 the parabola opens upward (has a minimum); if a<0 it opens downward (has a maximum).
  • Vertex (turning point): (−b/2a, (4ac−b²)/4a).
  • Axis of symmetry: the vertical line x=−b/2a through the vertex.
  • Domain = ℝ. Range = {y ≥ vertex-value} if a>0, {y ≤ vertex-value} if a<0.

Graphs of y=ax²: larger |a| makes the parabola narrower (steeper); smaller |a| wider.

The parabola family y=ax²

Graph of y=(x−k)²+c: shift y=x² right by k and up by c; vertex at (k,c).

Shifting y=x² to y=(x−3)²+2

Completing the square turns ax²+bx+c into vertex form:

ax²+bx+c = a(x + b/2a)² + (4ac−b²)/4a

so the vertex is (−b/2a, (4ac−b²)/4a).

Parabola y=x²+6x+11 = (x+3)²+2

Example: y=x²+6x+11 = (x+3)²+2 → vertex (−3,2), axis x=−3, y-intercept (0,11), no x-intercept (opens up, vertex above axis).

Example: y=−x²+2x+3 = −(x−1)²+4 → vertex (1,4), opens down, x-intercepts from −(x−1)²+4=0 → x=−1 or 3, y-intercept (0,3).

Parabola y=−x²+2x+3 (maximum)
✍️ Must-know: ✍️ Must-know: Vertex form y=a(x−k)²+c: vertex (k,c); minimum value c if a>0, maximum value c if a<0. Use completing the square to find the vertex of any quadratic.
