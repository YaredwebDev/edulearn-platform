🧮 Key facts to memorise

◌ Not started
  • Scalars: only magnitude. Vectors: magnitude + direction.
  • Resultant of collinear vectors: same direction ⇒ add; opposite ⇒ subtract (direction of larger).
  • Perpendicular vectors: R = √(A²+B²), tan θ = opposite/adjacent.
  • Component resolution (angle from x-axis): Ax = A cos θ, Ay = A sin θ.
  • Component method: Rx = ΣAx, Ry = ΣAy, R = √(Rx²+Ry²), tan θ = Ry/Rx.
  • Unit vectors î, ĵ have magnitude 1; A = Axî + Ayĵ; Â = A/|A|.
  • Dot product: A·B = AB cos θ = AxBx + AyBy; î·î = ĵ·ĵ = 1; î·ĵ = 0.
  • Applications: Work W = F·S; Power P = F·v.
  • Graphical methods are approximate; analytic (component) methods are exact.
  • Triangle law = head-to-tail; parallelogram law = tail-to-tail (resultant is diagonal); polygon law = many vectors head-to-tail.

✅ End-of-unit self-check: Can you (1) classify quantities as vector vs scalar; (2) state the types of vectors and give the negative of a given vector; (3) apply the triangle, parallelogram and polygon laws graphically; (4) add collinear and perpendicular vectors; (5) resolve a vector into components and combine vectors by the component method to get magnitude and direction (mind the quadrant); (6) find a unit vector along a given vector and express a vector in î/ĵ form; and (7) compute the dot product and use it for the angle between vectors, for work (W = F·S) and for power (P = F·v)? Re-answer the end-of-unit review too (least number of vectors for a zero resultant; effect of increasing the angle 0°→180° on the resultant magnitude; component signs in each quadrant; direction cosines).
