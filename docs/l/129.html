3.9 Application of Enzymes in Industries & Benefits

◌ Not started

Enzyme catalytic activity is hundreds-to-thousands of times more efficient than inorganic catalysts. Applications: food, feed, textile, paper-making, leather, detergents, pharmaceuticals and more. - Enzymes break large molecules into simpler ones (digestion, respiration). - Most food-industry enzymes now come from microbial fermentation (previously extracted from animal/plant organs). - Enzymes improve feed-starch/protein/mineral utilisation and prevent animal indigestion. - In pharmaceuticals: drugs, antibiotics, household products. - Washing powders/detergents use enzymes to break down protein, starch and fat stains.

Table 3.3 — enzyme applications (memorise key pairs): | Enzyme | Application/function | |---|---| | Cellulases | biofuel industry — break cellulose → sugars → cellulosic ethanol | | Ligninase | biofuel — pre-treatment of biomass | | Protease / Amylase / Lipase | biological detergent — remove protein/starch/fat stains | | Mannanase | biological detergent — remove guar-gum food stains | | Beta-glucanase | brewing — improve beer filtration | | Papain | culinary — tenderise meat | | Rennin | dairy — hydrolyses protein to make cheese | | Trypsin | food processing — hypo-allergenic baby foods | | Cellulases / Pectinase | food processing — clarify fruit juices | | Nuclease / DNA ligase / Polymerase | molecular biology — restriction digestion & PCR to make recombinant DNA |

✍️ Must-know pairs: papain → tenderise meat; rennin → cheese; pectinase → clarify fruit juice; protease/amylase/lipase → detergents; DNA polymerase/ligase → recombinant DNA.
