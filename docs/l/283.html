2.9 Molecular Orbital (MO) Theory

◌ Not started

MO theory: atomic orbitals combine to form molecular orbitals that belong to the whole molecule. - A bonding MO (σ1s) has lower energy than the separate atoms (electrons in it stabilise the molecule). The corresponding antibonding MO (σ*1s) has higher energy. - Electrons fill MOs by the same Aufbau / Hund / Pauli rules as atomic orbitals.

Bond order:

✍️ Must-know formula: Bond order = ½[(# electrons in bonding MOs) − (# electrons in antibonding MOs)]. A positive bond order = a stable bond; bond order 0 = no bond.

Energy order differs by electron count (~period 2): - For molecules with ≤ 14 electrons (B₂, C₂, N₂ …): order σ1s < σ1s < σ2s < σ2s < π2py = π2pz < σ2px < π2py = π2pz < σ2px. - For molecules with > 14 electrons (O₂, F₂): the σ2px drops below the π pair (order becomes …π2p < σ2px < π2p …), i.e. the σ orbital fills before π near O₂.

Worked MO examples: - H₂⁺: σ1s¹ → B.O. = ½(1−0) = ½ → exists (stable). - H₂: σ1s² → B.O. = 1 → stable. - He₂⁺: σ1s²σ1s¹ → B.O. = ½(2−1) = ½ → exists. - He₂: σ1s²σ1s² → B.O. = 0 → does not exist. - Li₂: inner σ1s²σ1s² cancel, σ2s² → B.O. = 1 (inner shell electrons ignored). - B₂: B.O. = 1 and is paramagnetic (two unpaired electrons in the π2p MOs). - C₂: B.O. = 2, diamagnetic. N₂: B.O. = 3, diamagnetic (very strong, triple bond). - O₂: B.O. = 2, and has two unpaired electrons in the π2p MOs → paramagnetic. This is the key MO prediction that VB theory fails to explain. - Series: O₂⁺ (B.O. 2.5) > O₂ (2) > O₂⁻ (1.5) > O₂²⁻ (1). - CN⁻** B.O. = 3; CN B.O. = 2.5; CN⁺ B.O. = 2. (B₂ and O₂ are the paramagnetic second-period molecules.)

Magnetic properties: a substance with unpaired electrons is paramagnetic (attracted into a magnetic field); if all electrons are paired it is diamagnetic (slightly repelled).

✋ Trap: MO bond order uses both bonding and antibonding electrons; filled antibonding orbitals cancel filled bonding orbitals (He₂ has B.O. 0). O₂ is paramagnetic because of two unpaired π* electrons — you can't explain this with a Lewis/VB double bond alone.
