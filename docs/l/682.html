3.4 Acceleration

◌ Not started
  • Acceleration: the rate of change of velocity — a measure of how much velocity changes in one second. A vector quantity. Symbol ⃗a. SI unit m/s².
  • Acceleration occurs when velocity changes in magnitude (speed up or slow down), direction, or both.
  • Average acceleration: ⃗a_av = (⃗v_f − ⃗v_i)/(t_f − t_i) = Δ⃗v/Δt.
  • If the body starts from rest, ⃗v_i = 0. If velocity decreases, it is decelerating motion (deceleration = negative of acceleration). If it comes to rest, ⃗v_f = 0.

Example 3.7: A train accelerates from rest to 36 km/h (10 m/s) in 20 s. a = (10 − 0)/20 = +0.5 m/s² (to the east). Example 3.8: v_i = 7.0 m/s, v_f = 12.0 m/s, a = 2.5 m/s². Δt = (12−7)/2.5 = 2 s. Note: 36 km/h = 10 m/s.
