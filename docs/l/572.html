Number of elements of a union

n(A ∪ B) = n(A) + n(B) − n(A ∩ B)

  • If A ∩ B = ∅, then n(A ∪ B) = n(A) + n(B).

Example: n(A) = 20, n(B) = 28, n(A∪B) = 36 → n(A∩B) = 20 + 28 − 36 = 12.

Worked application: In a meeting of 60 people, 42 drink tea and 27 drink coffee; everyone drinks at least one. Let T = tea-drinkers, C = coffee-drinkers. - n(T∪C) = 60 = n(T) + n(C) − n(T∩C) = 42 + 27 − n(T∩C) → n(T∩C) = 9 people drink both.

✍️ Must-know: For two sets, n(A∪B) = n(A) + n(B) − n(A∩B). Use a Venn diagram for word problems about "how many do X only / both / neither."
