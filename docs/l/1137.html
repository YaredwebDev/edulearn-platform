1.3 Applications of Relations and Functions

Linear model (forensics): height = 2.47·(femur length) + 54, for 40≤length≤55. Femur 44 cm → height ≈ 2.47(44)+54 = 162.68 ≈ 163 cm. Femur 51 cm → ≈180 cm.

Maximum/minimum problems: A parabola reaches a max or min at its vertex. The minimum of f(x)=(x+k)²+c is c; the maximum of f(x)=−(x+k)²+c is c.

Maximum value example y=−(x−3)²+1

Example: f(x)=−x²+6x−8 = −(x−3)²+1 → vertex (3,1), maximum value 1, range {y≤1}=(−∞,1].

Graphical method of solving quadratic equations

  1. Rearrange so one side is zero.
  2. Draw the graph of the quadratic function.
  3. The x-coordinates where the curve crosses the x-axis are the solutions.
  • Crosses at two points → two real solutions.
  • Touches at one point → one (repeated) solution.
  • Never crosses → no real solutions.
Solving x²−4=0 graphically

Example: y=x²−4 crosses x-axis at x=−2 and x=2 → solutions of x²−4=0 are −2, 2.

Example: y=x²−2x−3=(x−1)²−4 has vertex (1,−4), crosses at x=−1 and x=3.

Example: y=x²+4x+8=(x+2)²+4 opens up, vertex (−2,4) above axis → no real solution.

Graphical method of solving quadratic inequalities

  1. Write in standard form ax²+bx+c≥0 or ≤0.
  2. Graph the parabola.
  3. ax²+bx+c<0 → the portion where the parabola is below the x-axis; >0 → above.
Quadratic inequality x²−6x+8<0

Example: x²−6x+8<0. Roots at x=2 and x=4; parabola opens up, so it is below the axis between the roots. Solution (2,4) i.e. {x: 2<x<4}.

Example: −x²−8x−12≤0 = −(x+4)²+4 ≤0. Roots −6 and −2; opens down, so ≤0 outside the roots. Solution (−∞,−6]∪[−2,∞).

✍️ Must-know: ✍️ Must-know: For an upward parabola, <0 is between the roots, >0 is outside. For a downward parabola, <0 is outside the roots, >0 is between. Include endpoints only for ≤/≥.
