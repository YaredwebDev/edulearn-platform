2.2 Rational Numbers

◌ Not started

Definition: Any number that can be written as a/b where a, b ∈ ℤ and b ≠ 0. Denoted ℚ. - Every integer and natural number is rational (−6 = −6/1, 0 = 0/1). - Proper fraction: numerator < denominator. Improper fraction: numerator ≥ denominator. Mixed number: integer + proper fraction.

2.2.1 Decimals

Dividing numerator by denominator gives either: - Terminating decimal (division ends, remainder 0). E.g., 3/5 = 0.6. - Repeating decimal (remainder never 0, digits repeat). E.g., 5/9 = 0.555… = 0.5̅.

Bar notation marks the repeating block: 1/3 = 0.3̅, 23/99 = 0.2323… = 0.23̅ (both digits under one bar).

Converting terminating decimals to fractions: denominator is a power of 10. - 7.3 = 73/10; −0.18 = −18/100 = −9/50.

2.2.2 Converting repeating decimals to fractions

Method: Let d = the decimal. Multiply by a power of 10 so the repeating part aligns, subtract, and solve.

  • 0.5̅: d = 0.5̅ → 10d = 5.5̅ → 10d − d = 5 → 9d = 5 → d = 5/9.
  • 2.12̅ (repeating 12): d = 2.1212… → 100d = 212.12… → 99d = 210 → d = 210/99 = 70/33.
  • 0.12̅ (repeating 2): 100d = 12.2̅, 10d = 1.2̅ → 90d = 11 → d = 11/90.

Representing rational numbers on the number line

Convert fractions to decimals and mark them.

Example: Locate −5, 3, 4/3 (=1.3̅), −5/2 (=−2.5). Convert and place each fraction.
