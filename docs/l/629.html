3.1 Acceleration

◌ Not started

Acceleration is a vector = rate of change of velocity (change in velocity per unit time). SI unit m/s². - Average acceleration: ā = (v − u)/t = Δv/Δt. - Instantaneous acceleration a_ins: take the time interval Δt → 0; i.e. a_ins = Δv/Δt as Δt approaches zero.

Uniformly accelerated motion = motion in which velocity changes by equal amounts in equal intervals of time (constant acceleration).

✍️ Must-know: acceleration is a vector quantity with SI unit m/s²; when an object speeds up, acceleration is in the direction of velocity; when it slows (decelerating), acceleration opposes velocity.

Recognising acceleration in everyday life: a cheetah accelerating from rest to catch prey; an object sliding down an incline speeding up (an incline/ramp experiment is done to study uniformly accelerated motion). The textbook includes a lab/activity to measure acceleration along an inclined track.
