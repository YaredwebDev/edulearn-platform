5.2 Trigonometric Ratios

◌ Not started

Definition: The trigonometric ratios of an acute angle are ratios of two sides of a right-angled triangle. They depend only on the angle, not the size of the triangle.

For angle A in the right triangle (hypotenuse AC, opposite BC, adjacent AB): - sin A = opposite / hypotenuse = BC/AC - cos A = adjacent / hypotenuse = AB/AC - tan A = opposite / adjacent = BC/AB - tan A = sin A / cos A

Example: If sin A = 3/5, draw the triangle (BC = 3, AC = 5), then AB = √(25−9) = 4. So cos A = 4/5, tan A = 3/4.

✍️ Must-know: SOH-CAH-TOA: - sin = Opposite/Hypotenuse - cos = Adjacent/Hypotenuse - tan = Opposite/Adjacent

Trigonometric values of basic angles

45° (isosceles right triangle, legs = a, hyp = a√2): - sin 45° = 1/√2, cos 45° = 1/√2, tan 45° = 1.

30° and 60° (half of an equilateral triangle, e.g., sides 1, √3, 2): - sin 30° = 1/2, cos 30° = √3/2, tan 30° = 1/√3. - sin 60° = √3/2, cos 60° = 1/2, tan 60° = √3.

Complete table of basic values:

Angle sin cos tan
0° 0 1 0
30° 1/2 √3/2 1/√3
45° 1/√2 1/√2 1
60° √3/2 1/2 √3
90° 1 0 undefined

Remark: As the angle goes from 0° to 90°, sin increases 0→1, cos decreases 1→0, tan increases 0→∞ (1 at 45°).

✍️ Must-know: Memorize the table! Pattern for sin row: 0, 1/2, 1/√2, √3/2, 1 (i.e., √0/2, √1/2, √2/2, √3/2, √4/2). Cos row is sin reversed.

Using the trigonometric table

  • For angles 0°–45° read from the top row; for 45°–90° read from the bottom row.
  • sin 18° ≈ 0.309017; cos 37° ≈ 0.798636; tan 70° ≈ 2.747480.
  • Given cos A = 0.819152 → A = 35°.
  • Given sin A = 0.7565 → nearest degree is 49° (0.75471).
