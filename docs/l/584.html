  • Linear (1 var) ax + b = 0 → one solution.
  • Linear (2 vars) ax + by = c → line, infinite solutions.
  • System methods: table, substitution, elimination, graphical.
  • System classification by coefficient ratios (dependent/inconsistent/independent).
  • |x| = p → x = ±p; |x| = negative → no solution.
  • Quadratic ax²+bx+c=0; solve by factorization, completing square, or formula x=(−b±√D)/2a.
  • Discriminant D = b²−4ac (2 / 1 / 0 real roots).
  • Sum of roots = −b/a, product = c/a.
  • aˣ = aʸ ⟺ x = y.
  • Radical equations: isolate, raise power, check domain & verify.
