4.7 Electric Circuits

◌ Not started

An electric circuit = a path through which charges can flow. A simple circuit = a source of potential difference (battery) + a load (bulb) + wires + switch.

  • Load: any element that dissipates energy (bulb, resistor).
  • Closed circuit: a complete, unbroken path → current flows, bulb glows.
  • Open circuit: broken path (or open switch) → no current, bulb off.

Circuit components & symbols: bulb, battery, switch, resistor, voltmeter, ammeter, connecting lead.

✍️ Must-know: A closed circuit is needed for charge to flow; an open circuit stops current.
