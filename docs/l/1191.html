3.3 Solving Nonlinear Equations

3.3.1 Equations involving absolute value

  • |p| = |−p|; |p| ≥ 0.
  • For p ≥ 0: |x| = p means x = p or x = −p.
  • An absolute value equation has no solution if the absolute value equals a negative number (|x| = −1 has none).

Examples:

  • |x| = 4 → x = 4 or x = −4.
  • |x + 7| = 14 → x + 7 = 14 or x + 7 = −14 → x = 7 or x = −21.
  • 2|2x−1| − 1 = 5 → |2x−1| = 3 → 2x−1 = 3 or 2x−1 = −3 → x = 2 or x = −1.
✍️ Must-know: ✍️ Must-know: |x| = p (p ≥ 0) → x = p or x = −p. If |expression| = negative, there is NO solution.

3.3.2 Quadratic equations

Definition: ax² + bx + c = 0 with a, b, c ∈ ℝ and a ≠ 0. a = leading coefficient, b = middle-term coefficient, c = constant.

Methods:

  1. Factorization (set each factor to zero, use ab = 0 ⟺ a = 0 or b = 0).
  • x² − 6x − 16 = 0 → (x − 8)(x + 2) = 0 → x = 8 or x = −2.
  • x² + 6x + 9 = 0 → (x+3)² = 0 → x = −3 (one solution).
  • x² − 9 = 0 → (x−3)(x+3) = 0 → x = ±3.
  • 4x² + 4x + 1 = 0 → (2x+1)² = 0 → x = −1/2.
  1. Completing the square — add and subtract (b/2a)².
  • x² + 6x + 4 = 0 → (x+3)² − 5 = 0 → x = −3 ± √5.
  • x² + 6x + 7 = 0 → (x+3)² − 2 = 0 → x = −3 ± √2.
  1. Quadratic formula: x = (−b ± √(b²−4ac)) / (2a).
  • x² − 6x + 3 = 0 → x = [6 ± √(36−12)]/2 = 3 ± √6.

Discriminant D = b² − 4ac:

  • D > 0 → two distinct real roots.
  • D = 0 → exactly one real root (equal roots).
  • D < 0 → no real roots.

Examples:

  • x² + 2x + 2 = 0: D = 4 − 8 = −4 < 0 → no real roots.
  • x² + 18x + 81 = 0: D = 0 → one root, x = −9.
  • x² + 4x + 3 = 0: D = 4 > 0 → two roots, x = −1, −3.

Relations between roots and coefficients: for roots r₁, r₂:

  • r₁ + r₂ = −b/a
  • r₁ · r₂ = c/a

Example: For ax² + 6x + c = 0, if sum = −6/5 and product = 1/5: −6/a = −6/5 → a = 5; c/5 = 1/5 → c = 1. Equation: 5x² + 6x + 1 = 0.

3.3.3 Equations involving exponents and radicals

Exponent equations: for a > 0, aˣ = aʸ ⟺ x = y (make bases equal).

Examples:

  • 2ˣ = 8 = 2³ → x = 3.
  • 3ˣ = 1/27 = 3⁻³ → x = −3.
  • 8ˣ = 16 → 2³ˣ = 2⁴ → 3x = 4 → x = 4/3.
  • 2ˣ⁺⁴ = 32 = 2⁵ → x + 4 = 5 → x = 1.
  • 9ˣ⁺⁴ = 27 → 3²⁽ˣ⁺⁴⁾ = 3³ → 2x + 8 = 3 → x = −5/2.
  • (x² + 6x)^(1/4) = 2 → raise to 4th power → x² + 6x = 16 → x² + 6x − 16 = 0 → x = −8, 2.

Radical equations: contain variables in the radicand.

Steps: specify domain (radicand ≥ 0), isolate the radical, square/raise both sides, solve, verify.

Examples:

  • √(15−2x) = x: domain 0 ≤ x ≤ 15/2. Square: 15 − 2x = x² → x² + 2x − 15 = 0 → x = 3 or x = −5. Only x = 3 valid.
  • √(x+3) = 3x − 1: domain x ≥ 1/3. Square: x+3 = 9x²−6x+1 → 9x²−7x−2=0 → x=1 or x=−2/9. Only x = 1 valid.
  • √(2x+3) + √(x−2) = 4: domain x ≥ 2. Solve → x = 3 (x = 83 rejected).
✍️ Must-know: ✍️ Must-know: Always check solutions to radical/exponent equations against the domain. A "solution" that makes a radicand negative is rejected.
