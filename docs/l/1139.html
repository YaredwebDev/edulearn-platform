2.1 Definition of Polynomial Function

Definition (Polynomial function): Let n be a non-negative integer and let aₙ,aₙ₋₁,…,a₀ be real numbers with aₙ≠0. The function

p(x) = aₙxⁿ + aₙ₋₁xⁿ⁻¹ + … + a₂x² + a₁x + a₀

is called a polynomial function in one variable x of degree n.

Terminology:

  • Coefficients: aₙ,…,a₀.
  • Leading coefficient: aₙ (the nonzero coefficient of the highest power).
  • Leading term: aₙxⁿ.
  • Degree: n (the highest exponent).
  • Constant term: a₀.

Domain of any polynomial function = ℝ (all real numbers).

Examples:

  • f(x)=3x²+x−3: degree 2, leading coeff 3, constant −3.
  • g(x)=4x⁵−x⁴+3x³+(2/5)x²+5x−2: degree 5, leading coeff 4, constant −2.
  • g(x)=2(x⁴+½x²−2)+x+x⁴+1 = 3x⁴+x²+x−3: degree 4, leading coeff 3, constant −3.

Constant & zero polynomial:

  • f(x)=b, b≠0 → polynomial of degree 0.
  • f(x)=0 → the zero polynomial, no degree assigned.
✍️ Must-know: ✍️ Must-know: A polynomial's exponents must be non-negative integers. Terms like x⁻², 1/x, √x, x^(1/2), x^(1/3) make a function NOT a polynomial. Also its domain must be all real numbers.

Non-polynomials: g(x)=4x⁻²+3x⁻¹−7 (negative exponents), h(x)=2ˣ (variable in exponent), k(y)=√y (radical), f(x)=2x^(1/3)+5x^(1/2)−x+5 (fractional exponents).

✍️ Must-know: ✍️ Must-know: A polynomial function is over integers/rationals/reals if all its coefficients are integers/rationals/reals.
