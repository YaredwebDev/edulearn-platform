3.1 Exponents and Logarithms

◌ Not started

3.1.1 Exponents

aⁿ means a multiplied by itself n times (n factors). a is the base, n is the exponent. - (−a)ⁿ: the base is −a. But −aⁿ: the base is only a. So (−3)²=9 but −3²=−9. (3a)³=27a³ but 3a³=3a³.

Laws of exponents (integer/rational/irrational exponents): 1. aᵐ·aⁿ = aᵐ⁺ⁿ 2. aᵐ/aⁿ = aᵐ⁻ⁿ (a≠0) 3. (aᵐ)ⁿ = aᵐⁿ 4. (ab)ⁿ = aⁿbⁿ 5. (a/b)ⁿ = aⁿ/bⁿ (b≠0)

Zero & negative exponents (Def 3.2): a⁰=1 (a≠0); a⁻ⁿ=1/aⁿ. 0⁰ is undefined.

Rational exponents (Def 3.3, 3.4): - a^(1/n) = ⁿ√a (the nth root). For even n and negative a, it's undefined in reals; for odd n and negative a, it's defined (negative root). - a^(m/n) = (a^(1/n))ᵐ = (ⁿ√a)ᵐ. - a^(−m/n) = 1/(a^(m/n)). - Definition 3.5: a^(m/n) = ᵐ√(aᵐ) = (ⁿ√a)ᵐ.

Irrational exponents: aᵇ (b irrational) is the real number that aˣ approaches as x→b (e.g., 3^√2 ≈ 4.7288). All the exponent laws hold for irrational exponents too.

✍️ Must-know: (−a)ⁿ vs −aⁿ differ by where the minus sign sits. a⁰=1 for a≠0. a⁻ⁿ=1/aⁿ.

3.1.2 Logarithms

Definition (Def 3.6): For a>0, a≠1, c>0: logₐc = b ⟺ aᵇ = c. - "logₐc" is the exponent to which a must be raised to get c. - log₂8=3 (2³=8); log₃(1/9)=−2 (3⁻²=1/9); log₅1=0 (5⁰=1).

Properties of logarithms: 1. logₐ1 = 0 2. logₐa = 1 3. logₐaᵖ = p and a^(logₐp) = p (inverse property) 4. If logₐM=logₐN then M=N (one-to-one property)

Laws of logarithms (M,N>0, a>0,a≠1): 1. Product: logₐ(MN) = logₐM + logₐN 2. Power: logₐ(Mʳ) = r·logₐM 3. Quotient: logₐ(M/N) = logₐM − logₐN 4. Change of base: logₐM = (log_b M)/(log_b a)

Common mistakes to avoid: - logₐ(MN) ≠ (logₐM)(logₐN) - logₐ(M+N) ≠ logₐM + logₐN - logₐ(M/N) ≠ (logₐM)/(logₐN) - (logₐM)ʳ ≠ r·logₐM

✍️ Must-know: A logarithm is an exponent. Product→sum, quotient→difference, power→multiple. Never split log of a sum/product incorrectly.

Common logarithms (base 10): written log M (base 10 omitted). If p=m×10^c with 1≤m<10, then log p = log m + c, where log m is the mantissa and c is the characteristic.

Example: log 6,920 = log(6.92×10³) = log 6.92 + 3 = 0.8401 + 3 = 3.8401. log 0.00123 = log(1.23×10⁻³) = 0.0899 + (−3) → characteristic −3, mantissa 0.0899.

Antilogarithm: If log M = N, then M = antilog(N). Use the antilog table; for a characteristic c, multiply by 10^c. - antilog(3.0913) = antilog(0.0913)×10³ = 1.234×1000 = 1234. - For negative: antilog(−2.1202): rewrite −2.1202 = −3 + 0.8798, then antilog(0.8798)×10⁻³ = 7.582×10⁻³ = 0.007582.

Computation with logarithms: To compute a number M: (1) find log M using the laws, (2) take the antilog. Example: √254 → log = ½log254 = ½(2+log2.54)=1+½(0.4048)=1.2024 → antilog ≈ 15.93.
