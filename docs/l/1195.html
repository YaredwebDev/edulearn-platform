4.2 Systems of Linear Inequalities in Two Variables

Linear inequalities in two variables represent the unequal relation between two expressions in two variables.

Graphing procedure:

  1. Sketch the corresponding boundary line (equation).
  2. Use a solid line if ≤ or ≥ (points on line are solutions); dashed if < or >.
  3. Choose a test point not on the line (usually (0,0) unless on the line); if it satisfies the inequality, shade that side; otherwise shade the other side.
  4. For a system, the solution is the overlap (intersection) of the shaded regions.

Example 1: y > −x — dashed line y = −x, shade above.

Example 2: {y < 2x + 5; y > −x} — dashed lines, solution is the overlapping (dark) region.

System of linear inequalities

Example 3: {y ≤ x − 2; y > −3x + 5} — solid y = x−2 (shade below, since (0,0) fails), dashed y = −3x+5 (shade the side not containing (0,0)). Solution is the intersection.

Example 4: {2x + 3y ≥ 12; x − 4y > 1; x < 4} — rewrite as y ≥ −(2/3)x + 4 (solid, upper), y < (1/2)x − 1/4 (dashed, lower), x < 4 (dashed vertical, left). Solution is the triple overlap.

✍️ Must-know: ✍️ Must-know: solid ≤/≥, dashed </>. Test a point (e.g., (0,0)) to decide which side to shade. System solution = overlap of shadings.
