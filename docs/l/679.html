3.1 Position, Distance and Displacement

◌ Not started
  • Motion: a continuous change in the position of an object relative to the position of a fixed object called the reference frame.
  • Frame of reference: a set of coordinates used to determine the positions of objects.
  • A body is at rest if its position in a reference frame does not change with time; in motion if its position changes. Rest and motion are relative (a body at rest in one frame may be in motion in another).
  • Position: a measurement of a location with respect to some reference point (usually the origin). In one-dimensional motion we use the x-axis; positions can be negative or positive.

Distance: - The total path length traveled by a body. A scalar quantity (no direction). SI unit meter (m). Symbol s. Always positive (or zero).

Displacement: - The change in an object's position in a certain direction. A vector quantity. - ⃗S = ⃗X_f − ⃗X_i (final position minus initial position). - Independent of the path taken; if you return to your start, displacement = 0.

Distance Displacement
Length of path travelled Shortest distance between initial & final positions
Scalar Vector
Depends on path Depends only on initial & final positions
Can be ≥ magnitude of displacement Magnitude ≤ distance

Example 3.1: A cyclist rides 3 km west then 2 km east. Displacement = 1 km west; distance = 5 km; magnitude of displacement = 1 km.

Exercise: Displacement is zero if the final position equals the initial position.
