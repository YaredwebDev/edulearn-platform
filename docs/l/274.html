🧮 Key Equations to Memorise

◌ Not started
  • c = λν
  • E = hν = hc/λ (h = 6.63×10⁻³⁴ J·s)
  • E = mc²; m = h/(cλ) for a photon
  • KE_e = ½mv² = hν − hν₀ (photoelectric)
  • mvr = nh/2π (Bohr quantum condition)
  • r = n²a₀, a₀ = 0.53 Å
  • Eₙ = −R_H/n², R_H = 2.18×10⁻¹⁸ J
  • ΔE = −R_H(1/n_f² − 1/n_i²) = hν
  • λ = h/mv (de Broglie)
  • Atomic mass = Σ(isotopic mass × fractional abundance)
  • Heisenberg: Δx·Δp ≥ h/4π
