4.1 Revision on Linear Inequalities in One Variable

◌ Not started

An algebraic inequality connects an expression to another with <, ≤, >, or ≥.

Properties: - If a > b then a + c > b + c and a − c > b − c. - If a > b and m > 0 then ma > mb and a/m > b/m (positive: sign unchanged). - If a > b and m < 0 then ma < mb and a/m < b/m (negative: REVERSE the sign).

Examples: - x − 5 > 2 → x > 7. - 2x > 4 → x > 2. - (1/3)x < 1 → x < 3. - −3x > 6 → x < −2 (divided by negative, reversed). - 2x − 3 ≥ 1 → x ≥ 2.

✍️ Must-know: Multiplying or dividing both sides of an inequality by a negative number reverses the inequality sign. This is the most common error in this unit.

Intervals on the number line

  • Closed [a, b]: a ≤ x ≤ b (filled dots).
  • Open (a, b): a < x < b (open dots).
  • Half-open [a, b) or (a, b].

Examples: - x + 1 > −2 → x > −3 → interval (−3, ∞). Open dot at −3. - 3x − (x+2) ≥ 0 → 2x ≥ 2 → x ≥ 1 → interval [1, ∞). Closed dot at 1.

Examples with intervals: - x + 2 < −x + 6 → 2x < 4 → x < 2 → (−∞, 2). - −(2/3)x + 1/2 ≤ 5/6 → multiply by 6: −4x + 3 ≤ 5 → −4x ≤ 2 → x ≥ −1/2 (reversed). Interval [−1/2, ∞).

✍️ Must-know: Open dot (excluded) vs closed dot (included). ∞ is always written with an open parenthesis.
