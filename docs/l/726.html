  1. Scalars: distance, speed, mass, temperature, energy, power, time, volume.
  2. Vectors: displacement, velocity, acceleration, force, momentum, impulse, weight.
  3. Resultant max when vectors parallel; min when anti-parallel.
  4. Perpendicular vectors: R = √(A²+B²), θ = tan⁻¹(B/A).
  5. A − B = A + (−B).
  6. Resolution: Ax = A cos θ, Ay = A sin θ; A = √(Ax²+Ay²).
  7. Unit vector = magnitude 1; zero/null vector = magnitude 0.
