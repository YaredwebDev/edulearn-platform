2.1 Scales, Standards, Units (Prefixes)

Scales

  • Scale = a set of numbers, amounts, etc., used to measure or compare the level of something.
  • A scale contains the markings that show a certain amount of what is being measured. The more marks a measuring device has, the more precise the measurement can be.
  • Reading a scale: each small mark represents a fraction (e.g., a space between numbered values divided into 10 gives one-tenth (0.1) per mark; you can estimate one more decimal place).
Note: Example 2.1: The red line goes just past 3.3 but not to 3.4, about halfway → read as 3.35.
  • Digital instruments indicate the measured value in digital format (number + unit); easier to read and more accurate than analog instruments.

Standards

  • A standard is a conventional unit used to measure a physical quantity scientifically. A chosen standard must:
  • be readily accessible and possess a property that can be measured reliably;
  • yield the same result when measured by different people in different places.
  • Non-standard (traditional) measurements create inaccuracy and bias (e.g., measuring cotton by palm size, distance by footsteps).
  • In 2019 an International Committee revised the standards — the SI system (an adaptation of the metric system).

Definitions of SI base units:

  • Meter (m): the distance traveled by light in vacuum during a time of 1/299792458 s.
  • Second (s): 9 192 631 770 times the period of vibration of radiation from the caesium-133 atom.
  • Kilogram (kg): defined by the fixed numerical value of the Planck constant h = 6.62607015×10⁻³⁴ J·s.

Scientific Notation

  • A way of writing measured values too large or too small: d × 10ⁿ, where d is a decimal number between 0 and 10 (usually 1 ≤ d < 10), and n is an integer exponent.
  • If n > 0, move the decimal n places right (e.g., 3.24×10³ = 3240). If n < 0, move left (3.24×10⁻³ = 0.00324).

Significant Figures

  • Each non-zero digit is significant. Zeros count only if they are between two non-zero digits or at the end of the decimal part.
  • 2000 has 1 sig fig; 2000.0 has 5 sig figs.
  • Add/subtract: result has the same number of decimal places as the term with the fewest decimal places. (9.65 + 8.4 = 18.1, not 18.05.)
  • Multiply/divide: result has the same number of significant figures as the quantity with the fewest sig figs. (8.65 × 2.035 = 17.8, not 17.75845.)
  • Rounding: remove sig figs from the right, rounding as you go (6.827 → 6.83 to 3 sig figs).
