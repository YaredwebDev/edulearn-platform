📌 QUICK REVISION / MUST-KNOW BOX (Unit 7)

  • Congruent: same size & shape (SSS, SAS, ASA, RHS).
  • Similar: same shape, proportional sides, equal angles (AA, SSS, SAS).
  • Perimeter ratio = scale factor k.
  • Area ratio = k².
  • Applications: shadows, building heights, river widths use similar-triangle proportions.
