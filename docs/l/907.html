⚡ Quick Revision Box (Unit 3)

  1. Cell theory (Hooke, Schleiden & Schwann, Virchow): cells = units of life; cells arise from pre-existing cells.
  2. Ribosomes synthesize proteins; mitochondria = powerhouse (respiration); chloroplasts = photosynthesis; lysosomes = digestion.
  3. Prokaryote: no nucleus/membrane-bound organelles (bacteria). Eukaryote: nucleus + organelles.
  4. Plant cell: cell wall (cellulose), chloroplast, large vacuole. Animal cell: centriole, lysosome.
  5. Diffusion = high→low, no energy; Osmosis = water through membrane, no energy; Active transport = low→high, uses energy.
  6. Hypertonic → cell shrinks/plasmolyses; Hypotonic → cell turgid/bursts (hemolysis in animals); Isotonic → no change.
  7. Contractile vacuoles expel excess water (osmoregulation, e.g., amoeba).
  8. Levels: atom → molecule → organelle → cell → tissue → organ → system → organism.
  9. Schleiden (plants), Schwann (animals), Virchow (cells from cells).
  10. Rough ER = protein (has ribosomes); Smooth ER = lipid.
