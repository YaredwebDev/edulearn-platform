📌 QUICK REVISION / MUST-KNOW BOX (Unit 2)

  • Euclid: a = bq + r, 0 ≤ r < b.
  • Prime (2 factors) vs composite (>2); 1 is neither; 2 is the only even prime.
  • Divisibility rules for 2, 3, 4, 5, 6, 8, 9, 10.
  • Fundamental Theorem of Arithmetic: unique prime factorization.
  • GCF (least powers) and LCM (greatest powers); GCF × LCM = a×b.
  • Rational ℚ = a/b; terminating or repeating decimals.
  • Irrational = non-terminating, non-repeating; √a irrational if a not a perfect square.
  • ℝ = rational ∪ irrational.
  • Radicals: √a·√b=√ab, √a/√b=√(a/b), a√b=√(a²b).
  • Exponents laws; a⁰=1; a⁻ⁿ=1/aⁿ.
  • Absolute value |x|; distance = |a−b|.
  • Scientific notation a×10ⁿ, 1≤a<10.
  • Bounds = value ± ½(place value).
  • Rationalize denominators using conjugate.
