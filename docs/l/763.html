5.8 Applications of Magnetism

◌ Not started
  • Health/medicine: MRI (magnetic resonance imaging) uses powerful magnetic fields to produce detailed images; magnets used in cancer treatment (injecting magnetically sensitive fluid + heating to kill cancer cells).
  • In the home: refrigerator magnets, compass, credit-card magnetic strip, vacuum cleaners, blenders, washing machines (electric motors), phones, doorbells, toys.
  • Computers/electronics: hard drives store data using magnets; speakers/headphones convert electronic signals to sound.
  • Electric power/industry: generators (mechanical → electrical), motors (electrical → mechanical), recycling cranes lift metal, magnetic sorting separates ores, food processing removes metal bits.
  • Compasses/navigation: compass needles point North; early compasses used lodestone; modern magnets (neodymium, rare-earth) are stronger.

✍️ Must-know: Magnetism is applied in MRI, speakers, hard drives, generators/motors, recycling, and navigation (compass).
