📚 Unit 3 Summary (Key Facts)

  • Cell = smallest and basic unit of life.
  • Cell theory: all organisms composed of cells; cells are smallest unit of life; cells arise from pre-existing cells.
  • Common structures: nucleus, cytoplasm, cell membrane.
  • Organelles: ribosomes (protein), rough/smooth ER, Golgi, mitochondria (powerhouse), lysosomes (digestion), vacuoles, chloroplasts (photosynthesis), centrioles, cilia, flagella.
  • Prokaryotes (no nucleus, e.g., bacteria) vs eukaryotes (nucleus + organelles).
  • Plant vs animal cells: cell wall, chloroplast, large vacuole in plants; centriole, lysosome in animals.
  • Transport: passive (diffusion, osmosis — no energy) vs active (against gradient, uses energy).
  • Levels of organization: atom → molecule → organelle → cell → tissue → organ → system → organism.
