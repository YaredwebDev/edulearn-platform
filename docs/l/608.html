8.2 Representation of a Vector

◌ Not started
  • A vector is represented geometrically by a directed line segment with an arrow, e.g., AB→ (A = initial point, B = terminal point).
  • Represented algebraically by letters with arrows (ū, v̄) or bold letters (a, u), or as a column vector.

Column vector: any vector ā can be written as ā = (x, y), where x = horizontal component, y = vertical component. E.g., ā = (2, 3).

Equality of vectors

Two vectors are equal if and only if they have the same magnitude and direction. AB→ = CD→ if they are equal.

Opposite of a vector

The vector with the same magnitude but opposite direction is the negative of the vector, −ā. So a = −(−a); AB→ = −CD→ if opposite.

Parallel vectors

Vectors with the same or opposite direction are parallel.

Magnitude of a vector

  • If ā = (x, y), then |ā| = √(x² + y²).
  • For AB→ with A=(x₁,y₁), B=(x₂,y₂): |AB→| = √((x₂−x₁)² + (y₂−y₁)²) (distance formula).

Example: |ū| for ū = (4,3) → |ū| = √(16+9) = √25 = 5 units.

Example (coordinates): |AB→| with A=(2,2), B=(3,7) → √((3−2)²+(7−2)²) = √26.

Direction of a vector

The direction is the angle the vector makes with a reference direction (horizontal or vertical). Express as North/South, angle, East/West.

Example: A vector at 37° to the horizontal, with y-axis = North and x-axis = East, has complement 53°, so its direction is N 53° E.
