📌 QUICK REVISION / MUST-KNOW BOX (Unit 4)

  • Negative multiplier reverses the inequality sign.
  • Solid ≤/≥, dashed </>; shade the correct side using a test point.
  • |k| < c → −c < k < c (between). |k| > c → k > c or k < −c (split).
  • Quadratic inequality methods: product property, sign chart, graph.
  • Product: m·n>0 if same signs; m·n<0 if opposite signs.
  • Applications: "at least" ≥, "at most" ≤.
