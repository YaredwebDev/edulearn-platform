📝 Writing focus: Informal Letters

◌ Not started

A personal/informal letter has this structure: 1. Sender's address (top right) and date (below it). 2. Salutation: "Dear ...," / "Hi ...," 3. Opening: ask how the reader is. 4. Body: the main content (e.g. describe a trip, an accident, an experience). 5. Closing: "Best wishes," "Your friend," "Yours," + signature. 6. Friendly, conversational tone.

✍️ Must-know: The textbook provides two model informal letters. Study their layout (address → date → greeting → body paragraphs → sign-off) and the friendly tone used.

✅ End-of-unit self-check: Can you (1) list causes and prevention of traffic accidents, (2) define the 6+ vocabulary words and give synonyms/antonyms, (3) use all 12 modal verbs correctly, (4) choose do/does/don't/doesn't correctly, (5) place adverbs of frequency, (6) write a correctly formatted informal letter?
