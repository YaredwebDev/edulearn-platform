6.9 Color Subtraction of Light Using Filters

◌ Not started

Color subtraction: the colors absorbed are "subtracted" from the light seen. - A black object absorbs all colors; a white object reflects all colors. A blue object reflects blue and absorbs all others.

Subtractive primaries = cyan, magenta, yellow (opposite of additive primaries). - Cyan − Blue = (Green + Blue) − Blue = Green - Yellow − Green = (Red + Green) − Green = Red - Magenta − Red = (Red + Blue) − Red = Blue

Complementary colors: cyan's complement is red; magenta's complement is green; yellow's complement is blue.

  • Pigment = a substance giving an object its color by absorbing certain frequencies and reflecting others (e.g., a red pigment absorbs all colors except red).
  • Color filter = a device that lets only certain colors pass while absorbing the rest.
  • Yellow filter: absorbs blue, transmits red + green (seen as yellow).
  • Magenta filter: absorbs green, transmits red + blue (seen as magenta).
  • Cyan filter: absorbs red, transmits blue + green (seen as cyan).

Subtractive color mixing starts with white and ends with black; adding color makes the result darker (paints, printing).

✍️ Must-know: Subtractive primaries = Cyan, Magenta, Yellow. Yellow filter absorbs blue; magenta absorbs green; cyan absorbs red. Black absorbs all; white reflects all.
