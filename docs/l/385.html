7.3 Word Formation: Prefixes & Suffixes

◌ Not started
  • Prefix = added at the beginning of a root; has no meaning by itself but modifies meaning (negative, opinion, repetition): un- + happy = unhappy; dis- + organized = disorganized.
  • Suffix = added at the end; changes the word's class (verb→noun/adjective) rather than making it negative: forget + -ful = forgetful; happy + -ness = happiness.

Prefixes to practise (from the unit): bi-, de-, pre-, un-, im-, kilo-, out-, mis-, re-. Examples: immoral, rewrite, redesign, misbehave, unwise, unnecessary, bipolar, polar, annual, prefix/suffix fix, outdo, overweight, kilogram.

Suffixes to practise: -ship, -ment, -less, -fully, -er, -tion, -ness. Examples: joyfully, happiness, manage→management, kindness, leader→leadership, slow→slowly, mercy→merciless, inform→information, beautiful→beautifully, careless, mad→madness, tall→taller.

✍️ Must-know: Prefix = beginning, modifies meaning (un/dis/im/mis/re/bi/de/kilo/out). Suffix = end, changes word class (-ness, -ful, -less, -ship, -ment, -er, -tion, -ly). Know both directions: add the right affix and give the derived word.
