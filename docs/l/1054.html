7.5 Grammar

7.5.1 Conditional Sentences (all four types — core matric topic)

Conditional = if clause + main (result) clause. "If" can be replaced by provided that, on condition that, so long as.

TypeMeaningStructureExample
Type 0general truth (always true)If + present, presentIf you freeze water, it becomes solid.
Type 1possible & probable (real future)If + present, will + V1If you don't study, you will fail.
Type 2possible but improbable (unreal present)If + past (were), would + V1If I were you, I would take the offer.
Type 3impossible (unreal past)If + had + V3, would have + V3If I had not been rude, he would not have fired me.
  • The if clause and main clause can swap positions without changing meaning.
  • Type 2 wishes: "If I were a bird, I would fly." (use "were" for all persons).
  • Type 3: "They would have killed him if the police hadn't reached in time."
✍️ Must-know: ✍️ Must-know: Four types; match structure to meaning. Type 2 uses past/were; Type 3 uses had+V3 / would have+V3. Practice verbs: "If I were you, I would find a new job"; "I would be happy if I had visited my grandmother"; "If you mix yellow and green, you get blue" (type 0).

7.5.2 Direct and Reported (Indirect) Speech

  • Direct speech quotes the speaker's exact words: Edosa said, "I had lost my handbag."
  • Reported/indirect speech retells without quotes: Edosa said that he had lost his handbag.

Reporting-verb backshift (when the reporting verb is past):

Pronoun changes: I→he/she; you→he/she/they; me→him/her; my→his/her; we→they; us→them; our→their.

Time & place changes: this→that; these→those; now→then; today→that day; yesterday→the previous day; tomorrow→the following day; last night→the previous night; next day→the following day; ago→before; just→then; here→there.

say vs tell: say that… / tell someone that… ("Yohannes told me he could type it").

  • You can keep "that" in written English but often drop it in speech.
Note: ✋ Trap: shift EVERYTHING — the verb tense AND the pronoun AND the time word. "I will be in Jigjiga tomorrow" → "She said (that) she would be in Jigjiga the following day."
