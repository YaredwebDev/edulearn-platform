  • Relation = set of ordered pairs; domain = first coordinates, range = second.
  • Function: no two ordered pairs share the same first element (Vertical Line Test).
  • One-to-one (injective), onto (surjective), bijective (both).
  • Combinations: (f+g),(f−g),(fg),(f/g) with g≠0; domain = intersection of domains.
  • Linear f(x)=ax+b: slope a, y-int b, x-int −b/a; a>0 inc, a<0 dec.
  • Quadratic f(x)=ax²+bx+c: vertex (−b/2a,(4ac−b²)/4a), axis x=−b/2a; a>0 min/up, a<0 max/down.
  • Completing the square → vertex form y=a(x−k)²+c, vertex (k,c).
  • Inequality regions: solid for ≤/≥, dashed for </>; test a point to shade.
  • Quadratic equation solved graphically: read x-intercepts.
  • Quadratic inequality: solve by reading where parabola is above/below axis.
