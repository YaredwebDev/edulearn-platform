5.5 Mechanical Advantage, Velocity Ratio and Efficiency

◌ Not started

Mechanical Advantage (M.A)

  • When a machine turns a small input force into a larger output force, it gives mechanical advantage.
  • M.A = Output force / Input force = Load / Effort = F_L / F_E (5.3)
  • M.A has no units (a ratio).
  • M.A > 1 = force multiplier (load > effort). M.A = 1 if input = output.
  • Actual Mechanical Advantage (AMA): compares load with effort considering energy losses (friction).
  • Ideal Mechanical Advantage (IMA): mechanical advantage if there were no energy losses.
  • In the real world, IMA is always greater than AMA (friction). For calculations we often assume no losses, so AMA = IMA = MA.

Example 5.1: Load 400 N, effort 160 N → M.A = 400/160 = 2.5.

Velocity Ratio (V.R)

  • V.R = distance moved by effort / distance moved by load (5.4)
  • V.R has no units. If V.R = 3, effort moves 3× as far as load.
  • If V.R < 1, the machine multiplies speed/distance (load moves farther); if V.R > 1, it multiplies force.

Example 5.2: d_E = 40 cm, d_L = 10 cm → V.R = 40/10 = 4.

Efficiency (η)

  • Describes how good a machine is at transferring input energy to useful output energy.
  • Machines waste energy due to friction between moving parts, so efficiency is less than one (100%).
  • η = work output / work input = power output / power input (5.5)
  • Also expressed in terms of M.A and V.R:
  • η = M.A / V.R (5.7)
  • Efficiency has no units (ratio), often multiplied by 100 to give a percentage.

Example 5.3: Work output 80 J, work input 400 J → η = 80/400 = 0.2 = 20%. For 2000 J input → output = 0.2 × 2000 = 400 J. Exercise: M.A = 3, V.R = 6 → η = 3/6 = 0.5 = 50%. If M.A = V.R, machine is 100% efficient (ideal, no friction).

Levers

  • Lever: a rigid bar (wood or metal) free to turn about a supporting point called the fulcrum (F).
  • A lever has three parts: effort point (E), load point (L), and fulcrum (F).
  • Load arm: the part of the lever from the fulcrum to the load. Effort arm: from the fulcrum to where force is applied.
  • Archimedes: "Give me a place to stand and I shall move the Earth with a lever."

Three classes of levers: 1. First-class lever: fulcrum between load and effort. Examples: seesaw, scissors, crowbar. IMA can be >, =, or < 1. 2. Second-class lever: load between effort and fulcrum. Examples: wheelbarrow, nutcrackers, bottle opener. IMA always > 1. 3. Third-class lever: effort between load and fulcrum. Examples: fishing pole, tweezers, an arm lifting a weight, calipers, broom, hockey stick, tennis racket, spade, shovel. IMA always < 1.

M.A, V.R, and efficiency of levers: - M.A = load/effort = F_L/F_E (5.8) - V.R = d_E/d_L (distance from effort to fulcrum / distance from load to fulcrum) (5.9) - If no energy losses, IMA = V.R = d_E/d_L (5.10)

Example 5.4: L = 200 N, E = 80 N, d_L = 10 cm, d_E = 40 cm. V.R = 40/10 = 4; M.A = 200/80 = 2.5; η = M.A/V.R = 2.5/4 = 0.625 = 62.5%.

Inclined Plane, Wedge and Screw

Inclined plane (ramp): a sloping surface connecting two points; the simplest machine. Object lifted to height h by sliding it up the length l. - M.A = Load/Effort = L/E (5.11) - V.R = length of inclined surface / height = l/h (5.12)

Exercise: V.R of a slope 30 m long raising to 5 m = 30/5 = 6. For 40 m slope, 8 m height, effort 80 N, load 240 N: M.A = 3, V.R = 5, η = 60%.

Wedge: used to separate or split objects (knives, nails, axes, spears). Load = force on the object being split; effort = force applied to the top of the wedge. - M.A = L/E (5.13) - V.R = penetration length / thickness = l/t (5.14) - η = M.A/V.R = (L×t)/(E×l) (5.15) - The more narrow the wedge, the greater the ratio of penetration length to thickness.

Screw: a cylinder with a helical thread around it (includes nuts and bolts). In one turn it moves a distance equal to the separation between threads = the pitch (p). - M.A = πd/p = 2πr/p (5.16), where d = mean diameter (d = 2r) and p = pitch.

The Wheel and Axle

  • Wheel and axle: a large wheel secured to a smaller wheel called the axle.
  • If input force turns the wheel and output is on the axle: since the wheel is larger than the axle, mechanical advantage > 1 (force multiplier). Examples: screwdriver, drill, windmill, water wheel, doorknob.
  • If input force turns the axle (output on wheel): M.A < 1, output force < input force (speed multiplier). Examples: bicycle, car tires, electric fan.
  • M.A = L/E (5.17)
  • V.R = radius of wheel / radius of axle = R/r (5.18)
  • If no energy losses, V.R = M.A = IMA = R/r.

Exercise: If the wheel diameter is 20× the axle diameter, M.A = 20 (since ratio of radii = ratio of diameters).

The Pulley System

  • Pulley: a circular body (wheel) with a grooved surface, free to rotate about its center. Three types: 1. Fixed pulley: fixed axle, rope looped over the top. Used to change direction of force. Acts as a first-class lever. Advantage: no need to pull up/down. Disadvantage: you apply more effort than the load (needs more effort to lift). 2. Movable pulley: axle free to move up/down. Applying effort to one end gives ~2× force; V.R = 2 (pull 2 m of rope to lift 1 m). Advantage: less effort. Disadvantage: must pull/push up/down. 3. Compound pulley (block and tackle): combination of fixed and movable pulleys. Effort needed is less than half the load; advantage: less effort; disadvantage: travels a very long distance.
  • For pulleys: M.A = load/effort and V.R = IMA = N (number of sections of ropes used to lift the load).
  • For fixed and movable pulleys there are energy losses due to friction, so M.A < V.R.
