6.6 Interpreting Graphs

◌ Not started
  • A graph is a diagram of statistical data/numbers.
  • When describing a graph use these starters: "The number of late-comers increases/decreases…", "The pattern I notice in the graph is…", "The difference between … and … is…", "A probable reason for this is…", "As we observe on the graph, the number… declines."
  • Trend verbs/adverbs: increase, rise, grow, climb; decrease, drop, fall, decline; fluctuate; stable. Adverbs: gently, gradually, slightly, steadily, suddenly, sharply, dramatically.

Figure: Female students enrolment in secondary schools (bar graph) — practise describing it.

Figure: Migration rate in Ethiopia (World Population Prospects 2019).

✍️ Must-know: For graph questions, state the trend (increase/decrease/fluctuate), compare values ("the difference between X and Y is…"), and suggest a reason ("a probable reason is…"). Use trend vocabulary precisely (sharply, gradually, steadily).
