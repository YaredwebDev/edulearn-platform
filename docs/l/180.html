  1. Father of taxonomy = Carolus Linnaeus.
  2. Hierarchy: Kingdom → Phylum/Division → Class → Order → Family → Genus → Species.
  3. Three domains: Bacteria, Archaea, Eukarya.
  4. Species = group that reproduces to produce fertile offspring.
  5. Binomial name: genus (capital) + species (small), italicized when printed. Human = Homo sapiens.
  6. Five kingdoms (Whittaker 1969): Monera, Protista, Fungi, Plantae, Animalia.
  7. Monera = prokaryotic (no nucleus); Protista = all eukaryotes, most diverse.
  8. Fungi = cell wall of chitin, heterotrophic (absorb), decomposers.
  9. Plants = cell wall of cellulose, autotrophic; Animals = no cell wall, ingest food, have collagen, muscle + nerve cells.
  10. Viruses are not alive (not in any kingdom); replicate only in host cells.
  11. Invertebrates = no backbone; Vertebrates = fish, amphibians, reptiles, birds, mammals.
  12. Ethiopia: noug (Guizotia abyssinica), tef (Eragrostis tef), Ethiopian mustard (Brassica carinata).
