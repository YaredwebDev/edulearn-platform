3.4 Solving Exponential and Logarithmic Equations

◌ Not started

3.4.1 Solving Exponential Equations

An exponential equation has the variable in the exponent (e.g., 2ˣ=16, 3⁵ˣ=81).

Base-exponent property: For any x,y, a>0, a≠1: aˣ=aʸ ⟺ x=y.

Steps: 1. Isolate the exponential expression. 2. Take the logarithm of both sides (use the power law to bring the exponent down). 3. Solve for the variable.

Example: 2^(2x−1)=8=2³ → 2x−1=3 → x=2. (This is the x-coordinate where y=2^(2x−1) meets y=8.)

Example: 2^(x²−3x)=16=2⁴ → x²−3x=4 → x²−3x−4=0 → (x+1)(x−4)=0 → x=−1 or 4.

When bases differ: 2ˣ=20 → log2ˣ=log20 → x log2 = log20 → x=(log2+1)/log2 ≈ (0.3010+1)/0.3010 ≈ 4.322.

3.4.2 Solving Logarithmic Equations

A logarithmic equation involves the log of an expression with a variable (e.g., log₂(x+3)=4).

Steps: 1. State the universe (the log's argument must be >0). 2. Collect log terms on one side. 3. Write in exponential form. 4. Solve, then check the solution is in the universe.

Example: log₂(x+3)=4. Universe: x+3>0 → x>−3. x+3=2⁴=16 → x=13 (in universe). ✓

Example: log₃(5x−2)=2−log₃4. Universe x>2/5. log₃(4(5x−2))=2 → log₃(20x−8)=2 → 20x−8=9 → x=17/20 (>2/5 ✓).

Example: 3^(x+4)=2^(−x): (x+4)log3 = −x log2 → x(log3+log2) = −4log3 → x = −4log3/(log3+log2) ≈ −2.453.

✍️ Must-know: Always state the universe (argument>0) before solving log equations, and verify the answer satisfies it. For exponential equations, use the base-exponent property when possible, else take logs.
