3.2 The Exponential Functions and Their Graphs

◌ Not started

3.2.1 Exponential Functions

Definition (Def 3.8): The exponential function with base a is f(x)=aˣ where a>0, a≠1, and x is any real number. - a≠1 because 1ˣ=1 is constant. - The variable is in the exponent (unlike polynomials).

3.2.2 Graph of Exponential Functions

f(x)=2ˣ: domain ℝ, range (0,∞), y-intercept (0,1), no x-intercept, increasing, horizontal asymptote y=0 (x-axis).

f(x)=(½)ˣ: domain ℝ, range (0,∞), y-int (0,1), decreasing, horizontal asymptote y=0.

General shapes of y=aˣ: - a>1: increasing (rapid growth to the right, approaches x-axis to the left). - 0<a<1: decreasing (approaches x-axis to the right, rapid growth to the left).

Characteristics of y=aˣ (a>0,a≠1): - Domain ℝ; range ℝ⁺ (positive reals). - y-intercept (0,1); NO x-intercept. - Horizontal asymptote: the x-axis (y=0). - a>1 increasing; 0<a<1 decreasing.

✍️ Must-know: Exponential graph always passes through (0,1), never touches the x-axis, has y=0 as a horizontal asymptote. Increasing if a>1, decreasing if 0<a<1.

Natural exponential function (Def 3.9): f(x)=eˣ with base e ≈ 2.718281828… (e = limit of (1+1/n)ⁿ as n→∞). Since 2<e<3, its graph lies between 2ˣ and 3ˣ.

Example: y=−eˣ has y-int (0,−1), no x-intercept, asymptote y=0, domain ℝ, range (negative reals), decreasing.
