4.3 Trigonometric Identities and Equations

Pythagorean identities:

  1. sin²θ + cos²θ = 1
  2. 1 + tan²θ = sec²θ
  3. 1 + cot²θ = csc²θ

Example: θ in QIII, sinθ=−3/5 → cosθ=−√(1−9/25)=−4/5.

Example: θ in QIV, tanθ=−2 → sec²θ=1+4=5 → secθ=√5 (QIV cos>0), cosθ=1/√5.

✍️ Must-know: ✍️ Must-know: To find other trig ratios from one, use sin²+cos²=1 and the quadrant sign.

Addition/subtraction formulas:

  • sin(α+β)=sinαcosβ+cosαsinβ
  • sin(α−β)=sinαcosβ−cosαsinβ
  • cos(α+β)=cosαcosβ−sinαsinβ
  • cos(α−β)=cosαcosβ+sinαsinβ

Example: sin75°=sin(30°+45°)=sin30cos45+cos30sin45=(√2/2)(√3/2)+(√2/2)(1/2)=(√6+√2)/4. cos75°=(√6−√2)/4.

Double angle identities:

  • sin2θ=2sinθcosθ
  • cos2θ=cos²θ−sin²θ=1−2sin²θ=2cos²θ−1
  • tan2θ=2tanθ/(1−tan²θ)

Example: θ in QII, sinθ=3/5 → cosθ=−4/5 → sin2θ=2(3/5)(−4/5)=−24/25; cos2θ=cos²−sin²=7/25.

Half-angle identities:

  • sin(α/2)=±√((1−cosα)/2)
  • cos(α/2)=±√((1+cosα)/2)

(Sign depends on quadrant of α/2.)

Example: cos15°=cos(30°/2)=√((1+cos30°)/2)=√((1+√3/2)/2)=√(2+√3)/2.

Trigonometric equations

Solve using algebraic methods, identities, and reference angles. Use θ_R to find solutions in [0,2π), then add multiples of 2π.

Example: 2cosθ−1=0 → cosθ=1/2 → θ_R=π/3. cosθ>0 → QI & QIV → θ=π/3, 5π/3.

Example: 2sinθ=−1 → sinθ=−1/2 → θ_R=π/6. sin<0 → QIII & QIV → θ=7π/6, 11π/6 (then +2nπ).

Example: √3secθ+2=0 → cosθ=−√3/2 → θ_R=π/6. cos<0 → QII & QIII → θ=5π/6, 7π/6.

✍️ Must-know: ✍️ Must-know: For sinθ=k: use θ_R=sin⁻¹|k|; if k>0 solutions in QI&QII, if k<0 in QIII&QIV. For cosθ=k>0 in QI&QIV, k<0 in QII&QIII.
