1.3 The Notion of Sets

◌ Not started

Empty, finite, and infinite sets

  • Empty (null/void) set: contains no element; denoted { } or ∅.
  • A = {x : 1 < x < 2, x ∈ ℕ} is empty (no natural number between 1 and 2).
  • Finite set: has a definite number of elements.
  • Infinite set: not finite.

Equal, equivalent, universal, subset, proper subset

  • Equal sets (A = B): exactly the same elements. {1,2,3,4} = {4,3,2,1}.
  • Equivalent sets (A↔B or A~B): one-to-one correspondence, so n(A) = n(B). {1,2,3,4} and {Red,Blue,Green,Black} are equivalent (4 each).
  • Universal set (U): contains all related elements without repetition.
  • Subset (A ⊆ B): every element of A is in B.

(A ⊆ B means the set A lies entirely inside B — every element of A is also in B.)

  • Proper subset (A ⊂ B): A ⊆ B and A ≠ B.

✍️ Must-know — counting subsets: - Number of subsets of a set with n elements = 2ⁿ. - Number of proper subsets = 2ⁿ − 1. - Example: A = {1,2,3} has 2³ = 8 subsets and 7 proper subsets. - Any set is a subset of itself; the empty set is a subset of every set; ∅ is a proper subset of every non-empty set.

Example: For A = {2, 5, 7} and B = {2, 5, 7, 8}, A is a proper subset of B: A ⊂ B. Also B ⊄ A.
