⚡ Quick Revision Box (Unit 5)

◌ Not started
  1. Six simple machines: inclined plane, wedge, screw, lever, wheel & axle, pulley.
  2. M.A = Load/Effort (no units).
  3. V.R = distance moved by effort / distance moved by load (no units).
  4. Efficiency η = Work output/Work input = M.A/V.R (as %).
  5. Machines never 100% efficient (friction). IMA > AMA in reality.
  6. Force multiplier if M.A > 1 (load > effort).
  7. 1st-class lever: fulcrum in middle (seesaw, scissors, crowbar).
  8. 2nd-class lever: load in middle (wheelbarrow, nutcracker, bottle opener).
  9. 3rd-class lever: effort in middle (fishing pole, tweezers, broom).
  10. Inclined plane V.R = l/h; wedge V.R = l/t; screw M.A = πd/p; wheel & axle V.R = R/r; movable pulley V.R = 2; fixed pulley = direction changer.
