2.3 Irrational Numbers

2.3.1 Neither repeating nor terminating

  • Perfect square: a number that is a square of an integer (1, 4, 9, 16, …).
  • A square root of x is a number y such that y² = x. √25 = 5, also −5.
  • √2 ≈ 1.41421356… is neither terminating nor repeating, so it is irrational.

Definition: A decimal that is neither terminating nor repeating is an irrational number. If a is a natural number that is not a perfect square, then √a is irrational.

Examples (rational or irrational?):

  • √25 = 5 → rational.
  • √0.09 = 0.3 → rational.
  • 0.12345… (non-repeating) → irrational.
  • 0.010110111… → irrational.
  • 22/7 → rational (a fraction).
  • π → irrational.
✍️ Must-know: ✍️ Must-know: If a > 0, b > 0 and a < b, then √a < √b. E.g., √5 < √7 since 5 < 7.

Locating √2 on the number line

Use Pythagoras: draw a 1-unit vertical segment at point 1, then the hypotenuse has length √(1²+1²) = √2. With a compass, transfer this length to the number line.

2.3.2 Operations on irrational numbers

Rules (a>0, b>0):

  • √a × √b = √(ab)
  • √a ÷ √b = √(a/b)
  • a√b = √(a²b) and √(a²b) = a√b

Examples:

  • √2 × √3 = √6.
  • (2+√2)(1+√5) = 2 + 2√5 + √2 + √10.
  • (√5+√3)² = 5 + 2√15 + 3 = 8 + 2√15.
  • √2/√3 = √(2/3); −√18/√2 = −√9 = −3.
  • √8 + √2 = 2√2 + √2 = 3√2.
  • √18 + √50 = 3√2 + 5√2 = 8√2.
  • √72 − √8 = 6√2 − 2√2 = 4√2.
✍️ Must-know: ✍️ Must-know: Only like radicals (same index and same radicand) can be combined by addition/subtraction: 2√5 + √5 = 3√5. First simplify so radicals are like.
