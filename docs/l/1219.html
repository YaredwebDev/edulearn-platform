8.4 Position Vector

Definition: Vectors that start at the origin (O) are position vectors.

For AB→ with A=(x₁,y₁), B=(x₂,y₂), the position vector OP→ = P = (x₂−x₁, y₂−y₁) = (x, y).

Notation: OP→ = ū = (x, y) = xi + yj, where i = (1,0) and j = (0,1) are unit vectors in the x and y directions. x and y are the components of ū.

Magnitude: |ū| = √(x² + y²).

Position vector

Example: Position vector ū = (3, 4): starts at origin to (3,4) = 3i + 4j. |ū| = √(9+16) = 5. tan θ = 4/3 → θ ≈ 53°.

Example: Initial (1,3), terminal (2,2) → position vector (2−1, 2−3) = (1, −1).

Example: Initial (−1,−2), terminal (3,1) → (3+1, 1+2) = (4, 3).

✍️ Must-know: ✍️ Must-know: Position vector = (x₂−x₁, y₂−y₁). Magnitude |ū| = √(x²+y²). Direction from tan θ = y/x.
