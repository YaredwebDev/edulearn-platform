4.5 Writing

4.5.1 Report Writing

A report = an account of activities/events that took place in the past. Steps:

  1. Decide the purpose (inform / entertain / educate).
  2. Identify the most essential ideas per paragraph (major events, unforgettable experiences, challenges, remedial measures).
  3. Arrange the information by relevance.
  4. Write freely first (get ideas down, ignore errors).
  5. Take time, then edit (subject matter, flow, language, mechanics).
  6. Write the clean, careful final version.
  7. Review or get feedback before finalising.

Sample report topic (book): visit to Bonora Waterfalls in Sidama Region, Bensa Woreda.

4.5.2 Punctuation: Apostrophe (') and Quotation Marks (" ")

Apostrophe:

  • Possession: add 's to a singular owner (Belete's book); add 's to a plural that doesn't end in s (the children's bags); add only ' to a plural ending in s (the students' bags); joint ownership: "Fikadu and Kebede's book" (one book owned together); separate: "Belete's and Ayele's books" (two books).
  • Contraction: don't→don't; it is→it's; cannot→can't; I will→I'll.
  • ✋ Trap: "childrens" ✋ → children (already plural, no s). "the childrens' bags" ✋ → "the children's bags."

Quotation marks (" "):

  • Enclose direct speech and exact quotes: Mr. Dingamo said, "Our cooperation is the best tool…"
  • Use for titles of short works.
  • Capitalise and punctuate inside the quotation marks correctly.
✍️ Must-know: ✍️ Must-know: Apostrophe for possession vs plural. For a shared item → one 's at the end of the last name ("Fikadu and Kebede's book"); for separate items → 's on each ("Fikadu's and Kebede's books").

📝 Writing focus

  • Write a report about a place you visited (using the 7-step process).
  • Practise punctuating with apostrophes and quotation marks.
  • Write sentences showing "be going to" vs "will."
