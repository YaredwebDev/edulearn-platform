📚 Unit 3 Summary (Key Facts)

◌ Not started
  • Elasticity = regains shape; plasticity = permanent deformation; elastic limit is the maximum.
  • ρ = m/V; SG = ρ_substance/ρ_water (unitless, water at 4 °C).
  • Stress = F/A (N/m²); strain = fractional change (dimensionless).
  • Hooke's law: within elastic limit, stress ∝ strain; modulus = stress/strain.
  • Young modulus Y = (F/A)/(ΔL/L₀); steel is most elastic.
  • Static equilibrium: ΣF = 0 and Στ = 0; τ = F·r·sin θ.
