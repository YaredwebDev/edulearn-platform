10D.2 Homophones and homographs

  • Homophones = words with the same sound but different meaning/spelling: to/too/two; cent/scent/sent; peace/piece/peas; there/their/they're; pray/prey; peak/peek/pique.
  • Homographs = words with the same spelling but different meaning (some also differ in sound/pronunciation): bank (financial establishment) vs bank (river edge); sewer (waste conduit) vs sewer (one who sews); lead (metal) vs lead (to go in front); capital (main city) vs capital (big letter); object (to disagree) vs object (a thing); wound (an injury) vs wound (past of wind/to wrap); wind (moving air) vs wind (to twist).

10D.3 Phrasal verbs (rule/run)

  • rule out — exclude/eliminate/ban · run out — come to an end, exhaust supplies · run across — meet by chance · run away — escape · run into — collide with / meet unexpectedly · run over — crush (with a vehicle); go over · run up — accumulate (a debt/bill) · run down — stop functioning; criticise.
