1.1 Relations

A relation is a set of ordered pairs. In daily life we meet relations such as "m is greater than n," "line n is perpendicular to line m," brothers/sisters, teachers/students. In mathematics a relation links two things by a relating phrase (e.g., y = 2x, y > x, y ≤ x+2, x²+y²=1).

  • The set of first components of the ordered pairs is the domain of the relation.
  • The set of second components is the range of the relation.

Example: If R = {(x,y): y = 2x} where x,y are integers, then R contains (−2,−4),(−1,−2),(0,0),(1,2),(2,4). Domain = all integers; Range = all even integers.

✍️ Must-know: ✍️ Must-know: A relation is just a set of ordered pairs. Domain = set of first coordinates; Range = set of second coordinates. To find them, list what x-values and y-values actually occur.

1.1.4 Graphs of Relations

We can represent a relation graphically by plotting its ordered pairs in a Cartesian (xy) coordinate system.

To sketch the graph of a relation given by an inequality:

  1. Draw the graph of the boundary line(s).
  2. Use a solid line if the inequality is ≤ or ≥; use a broken (dashed) line if it is < or >.
  3. Take arbitrary test points on each side of the line.
  4. The region containing points that satisfy the relation is the graph.

Example (y > x): Draw y=x as a dashed line (points on it NOT included). Test (0,3) → 3>0 true, and (0,−2) → false. So the solution region is above the line y=x.

Graph of the relation y > x

Example (y ≤ x+2): Draw y=x+2 as a solid line. Test (1,0): 0≤1+2 true. Shade the region below the line containing (1,0).

Graph of the relation y ≤ x+2
✍️ Must-know: ✍️ Must-know: Solid line for ≤/≥ (boundary included), broken/dashed line for </> (boundary excluded). Always test a point not on the line to decide which side to shade.

Systems of inequalities: The graph of a system such as {y<x AND y>−x+2} is the overlap of the two individual regions. Solve the boundary equations to find the intersection point.

Graph of a system of two inequalities

Example: For {y<x and y>−x+2}, the intersection of the two lines is x=1 (from x = −x+2). Test (2,0): 2<0 is false, but in the worked example (2,0) satisfied both — check signs carefully. Domain = {x : x>1}, Range = ℝ.

✍️ Must-know: ✍️ Must-know: The graph of a relation given by an inequality is a region, not a curve. The graph of a relation given by an equation is a curve.
