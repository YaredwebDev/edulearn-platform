6.2 String, Pendulum and Spring

  • Pulse: a single traveling disturbance (created by flicking a string once). A wave is a series/train of pulses.

Periodic motion: a to-and-fro movement that repeats itself in a fixed time interval (heartbeat, clock ticking, swing).

Simple Pendulum

  • A simple pendulum = a point mass (the bob) suspended by a massless, un-stretchable string.
  • If displaced from equilibrium, it swings back and forth periodically.
  • Period of a simple pendulum: T = 2π√(L/g) (6.3), where L = length and g = acceleration due to gravity.
  • The period depends only on length (L) and g — it is independent of the mass of the bob.
Note: Example 6.1: L = 50 cm = 0.5 m, g = 9.8 m/s² → T = 2π√(0.5/9.8) = 1.42 s.
Note: Example 6.2: L = 1 m, T = 0.65π s → g = (2π/T)² × L = 9.47 m/s².

The Simple Spring (Hooke's Law)

  • An object of mass m attached to a fixed spring has an equilibrium position x = 0 (neither stretched nor compressed).
  • When displaced and released, it undergoes periodic to-and-fro motion.
  • Hooke's law: the restoring force is directly proportional to the displacement x from equilibrium.
  • F_res = −kx (6.4), where k = spring constant (stiffness), SI unit N/m. The negative sign indicates the restoring force acts opposite to the displacement.
  • Applied force: F_app = kx (6.5) (F_app = −F_res).
  • The spring force is always a restoring force — it always acts to return the object to equilibrium.
  • If k is large → stiff spring (lots of force for small displacement). If k is small → loose spring.
  • Period of a spring-mass system: T = 2π√(m/k) (6.6), where m = mass and k = spring constant.
  • The period depends only on mass and spring constant.
Note: Example 6.3: m = 2 kg, k = 200 N/m → T = 2π√(2/200) = 2π/10 = π/5 s.
