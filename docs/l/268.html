  • Atomic number (Z) = number of protons in the nucleus. All atoms of an element share the same Z; different elements differ in Z.
  • Mass number (A) = number of protons + neutrons.
  • Notation: ᴬ_Z X (e.g. ²⁷₁₃Al, ³²₁₆S).
  • amu (atomic mass unit) = 1/12 the mass of one carbon-12 atom.

1.4.2 Atomic mass and Isotopes

  • Isotopes: atoms of the same element (same Z) with different numbers of neutrons (different A). E.g. carbon: ⁹⁸.⁸⁹% ¹²C, 1.11% ¹³C, <0.01% ¹⁴C → three naturally occurring isotopes.
  • Atomic mass = weighted average of isotopic masses over their fractional abundances.
  • If n isotopes of masses A₁, A₂…Aₙ and fractional abundances f₁, f₂…fₙ: Average atomic mass A = A₁f₁ + A₂f₂ + … + Aₙfₙ

Example 1.2 (worked): Silver: ¹⁰⁷Ag (106.90509 amu, 51.84%) + ¹⁰⁹Ag (108.90476 amu, 48.16%). - Portion Ag-107 = 106.90509 × 0.5184 = 55.42 amu - Portion Ag-109 = 108.90476 × 0.4816 = 52.45 amu - Atomic mass of Ag = 55.42 + 52.45 = 107.87 amu

✍️ Must-know: "Element X with four isotopes all having 24 protons" = chromium (Cr, Z=24). Practice computing isotope abundance from atomic mass (boron: ¹⁰B 10.013, ¹¹B 11.009, atomic mass 10.811).
