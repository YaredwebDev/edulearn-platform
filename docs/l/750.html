4.9 Combination of Resistors

◌ Not started

Resistors in Series (single path): - Same current through each resistor: I = I₁ = I₂ = I₃ = ... - Voltages add: V = V₁ + V₂ + V₃ + ... - Equivalent resistance: R_eq = R₁ + R₂ + R₃ + ... (greater than any individual resistance).

Resistors in Parallel (multiple paths): - Same voltage across each: V = V₁ = V₂ = V₃ = ... - Currents add: I = I₁ + I₂ + I₃ + ... - Equivalent resistance: 1/R_eq = 1/R₁ + 1/R₂ + 1/R₃ + ... (less than the smallest resistance).

Property Series Parallel
Current I same in all I = I₁+I₂+I₃
Voltage V = V₁+V₂+V₃ V same in all
Equivalent R R_eq = R₁+R₂+R₃ 1/R_eq = 1/R₁+1/R₂+1/R₃

Analysis procedure for series-parallel circuits: start from the part farthest from the source, reduce to equivalent resistances, find total current, then expand back in reverse order.

Example 4.8 (series): R₁=12, R₂=3, R₃=4, R₄=5 Ω, V=12 V. R_eq = 24 Ω; I = 12/24 = 0.50 A.

Example 4.9 (parallel): R₁=12, R₂=12, R₃=6 Ω, V=12 V. 1/R_eq = 1/12+1/12+1/6 = 1/3 → R_eq = 3.0 Ω. I = 12/3 = 4.0 A. I₁=1.0, I₂=1.0, I₃=2.0 A.

Example 4.10 (series-parallel): 4 Ω in series with (5 Ω ∥ 9 Ω). R_parallel = 3.21 Ω; R_eq = 7.21 Ω; I = 6/7.21 = 0.830 A.

✍️ Must-know: Series: R_eq = sum (adds up, current same). Parallel: 1/R_eq = sum of reciprocals (voltage same, R_eq smaller).
