7.1 Distance Between Two Points

The Cartesian (xy) plane is divided into four quadrants by the x-axis (horizontal) and y-axis (vertical), meeting at the origin (0,0). Each point is an ordered pair (x,y).

Distance formula (Def 7.1): For P(x₁,y₁) and Q(x₂,y₂),

d = √((x₂−x₁)² + (y₂−y₁)²)

  • Horizontal: d=|x₂−x₁|. Vertical: d=|y₂−y₁|.
  • This follows from Pythagoras.
Distance between two points

Examples:

  • A(2,1), B(8,9): d=√(36+64)=10.
  • P(9,13), Q(4,1): d=√(25+144)=13.
  • R(0,−1), S(−3,3): d=√(9+16)=5.
✍️ Must-know: ✍️ Must-know: d=√((Δx)²+(Δy)²). Distance is always positive (zero only if points coincide).
