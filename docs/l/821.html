3.9 Difference between DNA and RNA

◌ Not started
Feature DNA RNA
Bases A, T, G, C A, U, G, C
Sugar Deoxyribose Ribose
Size Huge (codes for many proteins) Much smaller (one protein)
Stability Very stable Less stable (degraded quickly)
Strands Double-stranded (double helix) Single-stranded
Types — mRNA, tRNA, rRNA

Functions: - DNA: genetic material storing information for the next generation; replicates (copies) during cell reproduction; carries the genetic code; transcribed to mRNA, then translated into proteins. - RNA: genetic material in some viruses; enzymatic activity in others (ribozyme). - mRNA: moves genetic code from DNA to ribosomes. - tRNA: supplies amino acids for protein synthesis. - rRNA: forms the ribosome with proteins.

✍️ Must-know: DNA = double helix, deoxyribose, A-T-G-C; RNA = single strand, ribose, A-U-G-C.
