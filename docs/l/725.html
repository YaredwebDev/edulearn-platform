📚 Unit 1 Summary (Key Facts)

◌ Not started
  • Scalar = magnitude only; Vector = magnitude + direction.
  • Vector drawn as an arrow: length = magnitude, head = direction.
  • Vector addition = finding the resultant; subtraction = adding the negative.
  • Methods: triangle (2 vectors), parallelogram (2 vectors), polygon (>2 vectors).
  • Resolution: Ax = A cos θ, Ay = A sin θ; A = √(Ax² + Ay²).
