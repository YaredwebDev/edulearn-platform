7.3 Theorems on Similar Plane Figures

Similarity theorems (for triangles):

  1. AA (Angle-Angle): if two angles of one triangle are equal to two angles of another, the triangles are similar (the third angle is automatic). (Equiangular triangles are similar.)
  2. SSS: if the three corresponding sides are proportional, the triangles are similar.
  3. SAS: if two corresponding sides are proportional and the included angle is equal, the triangles are similar.

AA example: If m∠G = 48° and m∠M = 30° matching two angles, then △EFG ~ △LMN by AA.

SSS example: AB/DE = BC/EF = AC/DF = 2 → △ABC ~ △DEF.

SAS example: AB/DE = 12/6 = 2, AC/DF = 14/7 = 2, and ∠A = ∠D → △ABC ~ △DEF.

Using similarity to find missing sides: Since △ABC ~ △DEF, set up ratios. E.g., if AB/DE = BC/EF = AC/DF, use known values to solve for unknowns.

Find an angle: If △ABC ~ △DEF, corresponding angles are equal. Match longest with longest, shortest with shortest.

Pythagoras via similarity: In a right triangle ABC, drawing BD perpendicular to AC creates three similar right triangles (△ABC ~ △ADB ~ △BDC), which can prove b² + p² = h².

✍️ Must-know: ✍️ Must-know: AA, SSS, and SAS similarity. "Included" angle in SAS is between the two proportional sides.
