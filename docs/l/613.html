9.1 Statistical Data

◌ Not started

Definition: Statistics is the science of collecting, organizing, presenting, analyzing, and interpreting data so that one can make a generalization.

9.1.1 Collection and tabulation of statistical data

Data collection: gathering information from all relevant sources to answer a research problem.

Types of data: - Qualitative data — non-numerical characteristics (colour, sex, religion, town). - Quantitative data — numerical (scores, heights, weights, ages). - Continuous data — measured at any value along a scale (height, temperature, time). - Discrete data — counted (usually integers, e.g., number of children; shoe sizes can be halves).

Data collection methods: primary data, secondary data, interviews, direct observations, questionnaires, surveys.

  • Primary data — generated by the researcher (surveys, interviews, experiments).
  • Secondary data — used from data generated by large institutions (government, health facilities).
  • Interview — in-depth (individual) or focus group.
  • Direct observation — systematically selecting, watching, listening, recording behaviour.

Organization: tabulation — condensing data into a statistical table (rows/columns). Presentation: bar graphs, histograms, pie charts, pictograms, frequency polygons. Analysis: using mean, median, mode (central tendency) and dispersion. Interpretation: drawing conclusions about a population from a sample.

Population and sampling

  • Population: the complete collection of individuals, objects, or measurements with a common characteristic.
  • Census: an enumeration of a population (expensive, done every 5–10 years).
  • Sampling frame: the actual set of units from which a sample is drawn.
  • Sample: a small part of the population examined (since the whole is unmanageable, expensive, or destructive).

Example: Study of primary-school study time → population = all primary students; sample = 1,000 selected students.

9.1.2 Graphical presentation of statistical data

  • Frequency distribution table: lists each value (variable) and its frequency (how many times it occurs).
  • Grouped frequency distribution: data grouped into class intervals.
  • Variable: a characteristic that can be measured/observed and varies.

Pie chart: a circle divided into sectors; sector size proportional to frequency. E.g., 120 children: 50% white = 60, 30% purple = 36, 20% blue = 24.

Histogram: graphical representation of a frequency distribution — variable (V) on the x-axis, frequency (f) on the y-axis. Bars touch (no gaps) for continuous data.

Example (frequency table): Weights 55, 62, 49, 67, 55, 62, 62, 49, 67, 62, 55, 49 →

Weight (kg) 49 55 62 67
Frequency 3 3 4 2

Grouped example (ages of 20 customers): classes 0≤x<10 (2), 10≤x<20 (3), 20≤x<30 (3), 30≤x<40 (6), 40≤x<50 (3), 50≤x<60 (1), 60≤x<70 (2).

9.1.3 Measures of central tendency

Mean (average): x̄ = (x₁ + x₂ + … + xₙ)/n = Σx/n. From a frequency distribution: x̄ = Σfx / Σf.

Examples: - Textbooks 5,4,6,4,3,6,7 → x̄ = 35/7 = 5. - Test scores (freq): x̄ = (10(0)+20(4)+30(1)+40(3)+50(2))/10 = 330/10 = 33. - Pencils 6,5,6,5,3,6,6,10,10,3: freq 3(2),5(2),6(4),10(2) → x̄ = (6+10+24+20)/10 = 60/10 = 6.

Properties of the mean: 1. Sum of deviations from the mean = 0: Σ(x−x̄) = 0. 2. Adding p to each value → new mean = x̄ + p. 3. Subtracting p → new mean = x̄ − p. 4. Multiplying each by p → new mean = p·x̄. 5. Dividing each by p → new mean = x̄/p.

Median: the middle value of ordered data. - Odd number of values: the middle value. - Even number: the average of the two middle values.

Example: 65,55,89,56,35,14,56,55,87,45,92 → sorted 14,35,45,55,55,56,56,65,87,89,92 → median = 56 (the 6th of 11). - Even example: 14,35,45,55,55,56,56,65,87,89 → median = (55+56)/2 = 55.5.

✍️ Must-know: ALWAYS sort data before finding the median. For even n, average the two middle values.

Mode: the most frequent value. - Example: 5,10,20,20,30,35,35,35,40,50,70,70 → mode = 35. - Example (midterm scores): most frequent are 14 and 12 → two modes. - If no value repeats (1,3,6,7,9,8,10,17,18) → no mode. - The mode is not always unique; it can be used for qualitative data.

9.1.4 Measures of dispersion

Dispersion/variation is the scatter (spread) of data from a measure of central tendency.

Range: Range = Largest value − Smallest value.

Examples: - Scores 6,7,5,8,3,8,9,5,4,5.5 → range = 9 − 3 = 6. - Freq table values 1,2,4,5,6 → range = 6 − 1 = 5.

Variance: the mean of the squared deviations from the mean: σ² = Σ(x−x̄)² / n.

Standard deviation: the square root of the variance: σ = √σ² = √(Σ(x−x̄)²/n).

Steps: find mean → deviations (x−x̄) → square them → average (variance) → square root (σ).

Example (TVs sold): 13,8,4,9,7,12,10 → x̄ = 63/7 = 9. Deviations²: 16,1,25,0,4,9,1 → σ² = 56/7 = 8, σ = √8 ≈ 2.83.

Grouped example (hours watching TV, 48 students): x̄ = 432/48 = 9; Σf(x−x̄)² = 124 → σ² = 124/48 = 31/12 ≈ 2.58, σ ≈ 1.6.

Properties of variance/standard deviation: 1. Adding a constant k to each value → variance and σ unchanged. 2. Multiplying each value by c → new variance = c²·(old); new σ = |c|·(old).

Example: data 2,3,4,3: x̄ = 3; deviations −1,0,1,0; σ² = (1+0+1+0)/4 = 0.5; σ ≈ 0.707. Adding 3 → 5,6,7,6 → new x̄ = 6; σ² still 0.5, σ still 0.707.
