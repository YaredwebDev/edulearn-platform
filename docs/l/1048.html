6.7 Spelling Rules (important for the spelling question type)

  1. "i before e except after c" (or when it sounds like [a]/[e]): niece, belief, cashier, achieve, but conceit, ceiling, perceive, deceive, and leisure, height, heiress, but neighbor, weigh.
  2. Keep silent "e" when adding -able: manage→manageable, encourage→encourageable.
  3. Remove silent "e" when adding -y: shine→shiny (but dice→dicey).
  4. Plural with –ies if the noun ends in a consonant + y; only -s after a vowel + y: baby→babies, lorry→lorries, story→stories, but day→days, key→keys.
  5. Remove final -e when adding -ies: shine→shinnies, ice→icies (as per the text).
Note: ✋ Trap spellings (from the unit): mischiefs (not mischeifs), seized (not siezed), receipt (not reciept), received, sufficient, weight, foreign, sovereignty, species, neighbors.

📝 Writing focus

  • Write a summary of a given text.
  • Interpret a bar/line graph using the graph language.
  • Practise spelling rules and correct misspelled words.
  • Write cause-and-effect sentences about migration using discourse markers (because, as a result, consequently, due to).
Note: ✅ End-of-unit self-check: Can you (1) give the main idea of each migration paragraph, (2) define the vocabulary, (3) form hyphenated/compounds with correct plurals, (4) use "go" phrasal verbs, (5) choose present perfect/simple past/past perfect, (6) use prepositions at/in/of + positional, (7) build clauses of purpose, (8) describe a graph, (9) apply the spelling rules?
