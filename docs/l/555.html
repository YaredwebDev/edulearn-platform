6.1 Revision of Prisms and Cylinders

◌ Not started

Right prism with base area BA, base perimeter p, altitude (height) h: - Lateral surface area LSA = p·h - Total surface area TSA = LSA + 2BA - Volume V = BA·h

Example (triangular prism): triangle sides 3,4,5 (right-angled, legs 3&4). p=3+4+5=12, h=6 → LSA=72 cm². BA=½·3·4=6 → TSA=72+12=84 cm². V=6·6=36 cm³. Example (rectangular prism): 3×2 base, h=4 → LSA=40, BA=6, TSA=52, V=24.

Right circular cylinder with radius r, altitude h: - LSA = 2πrh - TSA = 2πrh + 2πr² = 2πr(h+r) - V = πr²h

Example: r=3, h=5 → TSA=2π·3·(5+3)=48π cm², V=π·9·5=45π cm³.

Example (hollow/annulus base): cylinder with inner radius 1, outer radius 4, h=6. BA=π(4²−1²)=15π; outer LSA=48π, inner LSA=12π → TSA=60π+2(15π)=90π; V=15π·6=90π.

✍️ Must-know: LSA = perimeter × height (prism) or 2πrh (cylinder). TSA adds two bases. V = base area × height for both.
