4.4 Quadratic Inequalities

◌ Not started

Definition: General forms ax² + bx + c < 0, ≤ 0, > 0, ≥ 0 (a ≠ 0).

4.4.1 Product properties

  • m·n > 0 iff (m > 0 and n > 0) or (m < 0 and n < 0).
  • m·n < 0 iff (m > 0 and n < 0) or (m < 0 and n > 0).

Examples: - (x−3)(x−1) < 0 → case 2: x−3<0 and x−1>0 → x<3 and x>1 → 1 < x < 3 → (1, 3). - (x−4)(x−2) > 0 → x>4 or x<2 → (−∞, 2) ∪ (4, ∞). - x² − x ≥ 12 → x² − x − 12 ≥ 0 → (x−4)(x+3) ≥ 0 → x ≥ 4 or x ≤ −3 → (−∞, −3] ∪ [4, ∞). - −x² + x + 12 ≤ 0 → x² − x − 12 ≥ 0 → same: x ≤ −3 or x ≥ 4.

4.4.2 Sign chart method

Factorize, find key points (roots), and test the sign of each factor in each interval.

Example: (x−4)(x+3) < 0 - Roots: x = −3, x = 4. - Intervals: x<−3, −3<x<4, x>4.

  • Product < 0 on −3 < x < 4 → solution (−3, 4).

Example: (x+3)(x+2) ≥ 0 → product ≥ 0 on x ≤ −3 or x ≥ −2 → (−∞, −3] ∪ [−2, ∞).

(Graphically, x²−x−12 ≥ 0 where the parabola is on/above the x-axis, i.e., x ≤ −3 or x ≥ 4.)

✍️ Must-know: A quadratic inequality can be solved by product property, sign chart, or graph. For ">0" the answer is two outside intervals; for "<0" the answer is the between interval.
