3.6 Punctuation: Brackets, Braces, Parentheses

  • Square brackets [ ] — add words inside a reported quote that aren't part of the original: "The president said that some of the research papers [presented in the seminar] show solved problems."
  • Braces { } — show a set of numbers (in mathematics): A = {b, f, j, o, t}.
  • Parentheses ( ) — add further detail or a qualifying remark: "Artist Dr. Tilahun Gessesse (1933–2001), the legendary singer, …"
