2.4 Real Numbers

◌ Not started

Definition: A number is real if it is rational or irrational. ℝ = ℚ ∪ irrationals.

  • Trichotomy: for reals a, b exactly one of ab holds.
  • Transitive: if a<b and b<c then a<c.
  • For non-negative a, b: if a² < b² then a < b.

Examples (compare): −8 < −2; 5/8 = 0.625 < 0.8; √2/3 ≈ 0.471 > 0.34; (√3/6)² = 3/36 < (2/3)² = 16/36, so √3/6 < 2/3.

2.4.1 Intervals

  • Closed [a, b]: a ≤ x ≤ b.
  • Open (a, b): a < x < b.
  • Half-open [a, b) or (a, b]: one endpoint included.
  • Infinity symbols: ∞ (right) and −∞ (left); always written with open parenthesis.

Examples: - Real numbers between 3 and 5 including both → [3, 5]. - Between −2 and 3/2 including −2, excluding 3/2 → [−2, 3/2). - Left of 2 excluding 2 → (−∞, 2). - Right of 0 including 0 → [0, ∞).

✍️ Must-know: Filled/closed dot = included ([ ]); open dot = excluded (( )). ∞ is always open.

2.4.2 Absolute value

|x| = x if x ≥ 0, and |x| = −x if x < 0. It is the distance from 0.

Examples: |4| = 4, |−2| = 2, |1/2| = 1/2, |−0.4| = 0.4, |−√2| = √2, |2 − √8| = √8 − 2 (since √8 > 2). - Distance between a and b on the number line = |a − b| = |b − a|.

2.4.3 Exponents and radicals

  • Exponential expression aⁿ: a is the base, n the exponent. 2³ = 8, (−3)⁴ = 81, −2³ = −8.
  • a⁰ = 1 (a≠0); a⁻ⁿ = 1/aⁿ.
  • Square root / cube root / nth root: if aⁿ = b then a is an nth root of b.
  • Principal nth root √ⁿb: positive nth root if b>0; negative if b<0 and n odd; 0 if b=0.
  • (1/n)th power: b^(1/n) = √ⁿb (for b real and n odd, or b≥0 and n even).
  • a^(m/n) = (a^(1/n))ᵐ.

Laws of exponents (a,b ∈ ℝ, n,m ∈ ℕ): - aⁿ × aᵐ = aⁿ⁺ᵐ - aⁿ / aᵐ = aⁿ⁻ᵐ (a≠0) - (aⁿ)ᵐ = aⁿᵐ - (a×b)ⁿ = aⁿ × bⁿ - (a/b)ⁿ = aⁿ/bⁿ (b≠0)

Examples: - 7^(1/2) × 7^(3/2) = 7² = 49. - (25×9)^(1/2) = 5×3 = 15. - (8/27)^(1/3) = 2/3. - √50 = 5√2.

Addition/subtraction of like radicals: √3 + √12 = √3 + 2√3 = 3√3; 2√18 − √2 + √8 = 6√2 − √2 + 2√2 = 7√2.

Operations on real numbers: - Sum/difference/product/quotient of two rationals → rational (rationals are closed under +, −, ×, ÷). - Sum of rational and irrational → irrational. - Product of non-zero rational and irrational → irrational.

Properties of ℝ: closure, commutative, associative, identity (0 and 1), inverse (additive −a, multiplicative 1/a), distributive a(b+c) = ab+ac.

Examples of inverses: additive inverse of √2 is −√2, multiplicative inverse is 1/√2; additive inverse of 3/4 is −3/4, multiplicative is 4/3; additive inverse of 0.5 is −0.5, multiplicative is 2.

2.4.4 Limit of accuracy

  • Rounding: if the next digit is 0–4, keep; if 5–9, round up.
  • 38,721 to nearest 100 → 38,700; to nearest 1000 → 39,000; to nearest 10,000 → 40,000.
  • Decimal places (d.p.): 10.673 to 1 d.p. → 10.7; 3.173 to 2 d.p. → 3.17.
  • Significant figures (s.f.): 2.364 to 2 s.f. → 2.4; 0.0062 to 1 s.f. → 0.006; 0.3041 to 2 s.f. → 0.30.
  • Lower/upper bound: bound = value ± (place value ÷ 2).
  • 872 kg to nearest kg: lower 871.5, upper 872.5; as inequality 871.5 ≤ wt < 872.5.
  • 10.7 to 1 d.p.: lower 10.65, upper 10.75.
  • Effect of operations: for sums/products, lower bound = sum/product of lower bounds; upper = sum/product of upper bounds.
  • Field 12 m × 6 m: 11.5 ≤ l < 12.5, 5.5 ≤ w < 6.5; sum between 17 and 19; area between 63.25 and 81.25.

✍️ Must-know: Lower/upper bound = value ± ½×(place value). For + and ×, min uses the lower bounds and max uses the upper bounds.

2.4.5 Standard (scientific) notation

a × 10ⁿ with 1 ≤ a < 10 and n an integer. - 1,856,700,000 = 1.8567 × 10⁹. - 0.000000314 = 3.14 × 10⁻⁷. - 5.37 × 10⁶ = 5,370,000; 1.7 × 10⁻⁷ = 0.00000017.

2.4.6 Rationalization

Change an irrational denominator into a rational one by multiplying by the rationalizing factor (= 1). - 2/√3 × √3/√3 = 2√3/3. - √2/√5 × √5/√5 = √10/5. - 1/√2³ × √2²/√2² = √2²/2 = √4/2.

For sums with radicals use the conjugate: - 1/(√2+1) × (√2−1)/(√2−1) = √2 − 1. - 3/(√5−√3) × (√5+√3)/(√5+√3) = 3(√5+√3)/2. - Useful: (√a−√b)(√a+√b) = a−b; (a+√b)(a−√b) = a²−b.
