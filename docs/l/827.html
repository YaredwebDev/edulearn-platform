5.8 Using KC/KP — extent and direction

◌ Not started

Predicting extent: very large KC/KP (> ~10¹⁰) → equilibrium lies far right (mainly products, reaction near completion). Very small KC/KP (< ~10⁻¹⁰) → lies far left (mainly reactants, essentially no reaction). KC > 1 favours products; KC < 1 favours reactants; KC = 1 → equal amounts.

Reaction quotient Q: same form as KC/KP but using concentrations at any moment (not necessarily at equilibrium). Compare Q with K:

✍️ Must-know: if Q = K reaction is at equilibrium; if Q < K it proceeds forward (right, → more products); if Q > K it proceeds reverse (left, → more reactants).

Worked Example 5.6: CO + Cl₂ ⇌ COCl₂, KC = 13.8. [CO]₀=2.5 M, [Cl₂]₀=1.2 M, [COCl₂]₀=5.0 M. QC = 5.0/(2.5×1.2) = 1.67. Since QC (1.67) < KC (13.8), the mixture is not at equilibrium; it proceeds forward (right) to form more product.

Calculating equilibrium concentrations (systematic steps): (1) write balanced eqn & KC/KP; (2) list initial concentrations; (3) compute Q to find direction; (4) define change x (using coefficient ratios) and write equilibrium concentrations; (5) substitute into KC/KP and solve (may be a quadratic); (6) check that the value(s) satisfy the expression; discard unreasonable x (e.g. x > initial concentration).

Worked Example 5.7: H₂ + I₂ ⇌ 2HI, KC = 69. Start with 1 mol H₂ and 2 mol I₂ in 0.5 L → [H₂]₀=2.0 M, [I₂]₀=4.0 M, [HI]₀=0. Let x = [H₂] consumed. Equilibrium: [H₂]=2.0−x, [I₂]=4.0−x, [HI]=2x. KC = (2x)²/[(2.0−x)(4.0−x)] = 69 (textbook notes ~64–69). Solving the quadratic 60x² − 384x + 512 = 0 gives x = 1.9 M or 4.5 M; since x cannot exceed 2.0 M (initial [H₂]), x = 1.9 M. Equilibrium: [H₂] = 0.1 M, [I₂] = 2.1 M, [HI] = 3.8 M. Check: (3.8)²/(0.1×2.1) ≈ 68.8 ≈ 69 ✓.
