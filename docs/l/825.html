5.6 Relationship between KC and KP

◌ Not started

Using the ideal gas law, partial pressure P = (n/V)RT = CRT for each gas:

✍️ Must-know: KP = KC(RT)^Δn, where Δn = (c+d) − (a+b) for gaseous species only. If Δn = 0 then KP = KC.

Worked Example 5.4(1): 2SO₃ ⇌ 2SO₂ + O₂, KP = 1.8×10⁻³ kPa (1.8 Nm⁻²... treat as kPa), T = 427 °C = 700 K. Δn = (2+1)−2 = 1. KC = KP/(RT) → KC ≈ 3.1×10⁻⁴ (using R in matching units). Worked Example 5.4(2): CaCO₃(s) ⇌ CaO(s) + CO₂(g) with P_CO₂ = 3.87 atm. KP = 3.87. Δn = +1. KC = KP/(RT) = 3.87/(0.082×1273) = 0.037 M. (Note ΔH of reaction treated as given ~1273 K context.) Worked Example 5.4(3): H₂ + I₂ ⇌ 2HI. Δn = 2−1−1 = 0, so KP = KC = 64. If P_H₂=0.20 atm, P_I₂=0.50 atm: P_HI² = KP·P_H₂·P_I₂ = 64×0.20×0.50 → P_HI = 2.53 atm.
