⚡ Quick Revision Box (Unit 7)

  1. T_K = T_C + 273.15; T_C = T_K − 273.15.
  2. T_C = 5/9(T_F − 32); T_F = 9/5 T_C + 32.
  3. Size of 1 K = size of 1 °C (temperature differences equal).
  4. Absolute zero = 0 K = −273.15 °C.
  5. Fixed points: water ice point 0 °C/32 °F/273.15 K; boiling point 100 °C/212 °F/373.15 K.
  6. Linear expansion: ΔL = α·L₀·ΔT (α in °C⁻¹).
  7. Gases expand more than liquids; liquids more than solids.
  8. Mercury thermometer: −30 to 300 °C; alcohol: −115 to 78.15 °C; thermocouple: up to 2300 °C.
  9. Thermistor: NTC (resistance ↓ as temp ↑) and PTC (resistance ↑ as temp ↑).
  10. Greenhouse gases trap heat → greenhouse effect → global warming.
  11. Coefficient α: quartz (fused) smallest 0.5×10⁻⁶; lead largest 2.9×10⁻⁵.
