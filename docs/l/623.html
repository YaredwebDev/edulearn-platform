2.1 Vectors and Types of Vectors

◌ Not started

A quantity described by a single number only is a scalar. A quantity described by both a magnitude and a direction in space is a vector.

✍️ Must-know: scalars need only magnitude (e.g. area, density, distance, pressure, volume, power, speed, temperature); vectors need magnitude and direction (e.g. displacement, velocity, acceleration, force, weight).

Representation of vectors: a vector is represented graphically by an arrow drawn to scale — the length is proportional to magnitude and the arrowhead shows direction. We typically draw vectors on graph paper using a ruler and protractor.

Types of vectors (based on direction, magnitude and orientation): - Parallel vectors — same direction. - Antiparallel vectors — opposite directions. - Equal vectors — same magnitude and same direction. - Negative of a vector (−A) — same magnitude, opposite direction.

✋ Trap: the negative of a vector has the same magnitude but opposite direction. e.g. if S = 60 km North, then −S = 60 km South; if v = 100 km/h toward 20° South of East, then −v = 100 km/h toward 20° North of West.

Worked Example 2.1 logic: for any vector given with a compass direction, reverse the direction to get the negative.
