1.4 Operations on Sets

◌ Not started

A Venn diagram represents sets as interlocking circles enclosed in a rectangle (the universal set U).

Union and Intersection

  • Union (A ∪ B) = {x : x ∈ A or x ∈ B} — everything in A or B (or both).
  • Intersection (A ∩ B) = {x : x ∈ A and x ∈ B} — elements common to both.
  • Two sets are disjoint if A ∩ B = ∅.

Example: U = natural numbers < 12, A = {1,2,3,4,5,6}, B = {1,3,5,7,9}. - A ∪ B = {1,2,3,4,5,6,7,9} - A ∩ B = {1,3,5}

Complement

  • Complement of A (A′) = {x : x ∈ U and x ∉ A} — everything in U not in A.

Example: U = {0,1,2,3,4}, A = {3,4} → A′ = {0,1,2}.

Difference of sets

  • A − B (or A \ B) = {x : x ∈ A and x ∉ B} — elements of A not in B. This is the relative complement of A w.r.t. B.

Example: A = {0,1,2,3,4}, B = {3,4} → A − B = {0,1,2}.

Key identities (Theorem 1.1): - (A′)' = A - A′ = U − A - A − B = A ∩ B′ - A ⊆ B ⟺ B′ ⊆ A′

Symmetric Difference

  • A Δ B = (A \ B) ∪ (B \ A) = (A ∪ B) \ (A ∩ B).

Example: A = {1,2,4,5,8}, B = {2,3,5,7}. Then A\B = {1,4,8}, B\A = {3,7}, so AΔB = {1,3,4,7,8}.

Cartesian Product

  • A × B = {(a,b) : a ∈ A and b ∈ B} — the set of all ordered pairs.

Example: A = {1,2}, B = {a,b} → A×B = {(1,a),(1,b),(2,a),(2,b)}. - If A×B = {(1,a),(1,b),(2,a),(2,b),(3,a),(3,b)}, then A = {1,2,3}, B = {a,b}. - n(A × B) = n(A) × n(B).

✍️ Must-know — De Morgan's Laws: - 1st: (A ∪ B)′ = A′ ∩ B′ - 2nd: (A ∩ B)′ = A′ ∪ B′ These are extremely common in exams. Also know A − B = A ∩ B′.
