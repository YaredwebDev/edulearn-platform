3.1 Revision on Linear Equation in One Variable

Definition: An equation in one variable with exponent 1 is linear, of the form ax + b = 0 (a, b real, a≠0). It has exactly one solution.

Steps to solve:

  1. Clear fractions using the LCM.
  2. Simplify both sides.
  3. Isolate the variable.
  4. Verify the answer.

Examples:

  • x + 2 = 0 → x = −2.
  • 3x + 4 = 10 → 3x = 6 → x = 2.
  • (5/4)x + 1/2 = 2x − 1/2 → multiply by 4 → 5x + 2 = 8x − 2 → x = 4/3.

Worked problem: An isosceles triangle has each leg 6 cm more than the base; perimeter = 54 cm. Let base = a, each leg = a+6. Then a + 2(a+6) = 54 → 3a + 12 = 54 → a = 14. So base = 14 cm, legs = 20 cm each.

✍️ Must-know: ✍️ Must-know: A linear equation in one variable, ax + b = 0 (a≠0), has exactly one solution.
