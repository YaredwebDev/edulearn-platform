2.4 Zeros of a Polynomial Function

Definition (Zero): For a polynomial f(x), a real number c is a zero if f(c)=0. (Zeros = roots of f(x)=0 = x-intercepts of the graph.)

  • If (x−c) is a factor, c is a zero (and vice versa).
  • To find zeros: set f(x)=0 and factor.

Example: f(x)=(x−2)(3x+4)(1−4x) → zeros x=2, x=−4/3, x=1/4.

Example: f(x)=x⁴−13x²+36=(x²−4)(x²−9)=(x−2)(x+2)(x−3)(x+3) → zeros ±2, ±3.

Multiplicity (Def 2.8)

If (x−c)ᵏ is a factor of f(x) but (x−c)ᵏ⁺¹ is not, then c is a zero of multiplicity k.

  • k=1 → simple zero. k>1 → repeated (multiple) zero.

Example: f(x)=x³+2x²−x−2=(x−1)(x+1)(x+2): all simple zeros.

g(x)=x³+4x²−3x−18=(x+3)²(x−2): zero −3 has multiplicity 2; zero 2 is simple.

Building a polynomial from zeros: If zeros are z₁,z₂,… and you need f(p)=k, use f(x)=a(x−z₁)(x−z₂)…, solve for a. Example: degree 2 with zeros 1,−2 and f(3)=30 → f(x)=a(x−1)(x+2); f(3)=a(2)(5)=10a=30 → a=3 → f(x)=3(x−1)(x+2).

✍️ Must-know: ✍️ Must-know: Zero of multiplicity m: if m is odd the graph crosses the x-axis; if m is even the graph touches (bounces off) the axis.

Location Theorem (Thm 2.4)

If f is a polynomial and f(a) and f(b) have opposite signs (a<b), then there is at least one zero of f between a and b.

Example: f(x)=x⁶−2x⁵−4x²+4x+4: f(1)=3>0, f(2)=−4<0 → zero between 1 and 2.

✍️ Must-know: ✍️ Must-know: Opposite signs at two points guarantee a zero between them. Same signs give no guarantee.

Rational Zero Test (Thm 2.5)

If all coefficients of f(x)=aₙxⁿ+…+a₀ are integers (aₙ≠0, a₀≠0) and p/q in lowest terms is a zero, then p is a factor of a₀ and q is a factor of aₙ.

Steps: list factors of a₀ (p's), factors of aₙ (q's), form all ±p/q, test which give f(p/q)=0.

Example: f(x)=x²+x−2: p=±1,±2; q=±1; candidates ±1,±2. f(−2)=0, f(1)=0 → zeros −2, 1.

Example: f(x)=6x³+13x²+x−2: p=±1,±2; q=1,2,3,6 → candidates ±1,±½,±⅓,±⅙,±2,±⅔. f(−½)=f(−2)=f(⅓)=0 → zeros −½,−2,⅓ → factor f(x)=(3x−1)(2x+1)(x+2).

✍️ Must-know: ✍️ Must-know: Rational zeros are of the form (factor of constant term)/(factor of leading coefficient). This only finds RATIONAL zeros; irrational and complex zeros are missed.
