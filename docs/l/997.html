4.3 The Modern Periodic Table

4.3.1 The Periodic Law

Note: "The physical and chemical properties of the elements are the periodic function of their atomic number." (Modern law — based on Moseley's work.)
  • The long form of the periodic table is based on the modern periodic law.
  • Left and right corners = subgroups A; middle = subgroups B.

4.3.2 Groups and Periods

Periods (horizontal rows):

  • Elements arranged in increasing atomic number left to right.
  • 7 periods (Arabic numerals 1–7).
  • Elements in the same period have the same number of shells (period number = number of shells).
  • Periods 1, 2, 3 = short periods; 4, 5, 6 = long periods.
  • Period 1 = 2 elements (H, He); Periods 2 & 3 = 8 elements each; Periods 4 & 5 = 18 each; Period 6 = 32; Period 7 = 32 (radioactive/artificial).
  • Except period 1, all periods start with an alkali metal and end with a noble gas.

Electron configurations (ground state): the lowest-energy arrangement. Notation = coefficient (main energy level) + letter (sublevel) + superscript (number of electrons).

  • 1s²2s²2p⁶3s¹ = Na (2, 8, 1) → 3 shells → period 3.
  • F (Z=9) = 1s²2s²2p⁵ (2, 7); Cl (Z=17) = 1s²2s²2p⁶3s²3p⁵ (2, 8, 7). Both have 7 valence electrons; F has 2 shells, Cl has 3.

Groups (vertical columns):

  • 18 columns/groups in the modern periodic table (I–VIII with A or B).
  • Main groups (A): IA–VIIIA. Subgroups (B): IB–VIIIB.
  • Elements in the same group have the same number of outermost (valence) electrons and similar chemical properties.
  • For main-group elements, group number = number of valence electrons. (Cl has 7 valence electrons → Group VIIA.)

4.3.3 Classification of the Elements (s, p, d, f blocks)

  • Based on the sublevel into which the last electron enters:
  1. s-block: last electron enters an s-orbital; valence config ns¹⁻² ([IG]ns¹ for alkali, [IG]ns² for alkaline earth).
  2. p-block: last electron enters a p-orbital; valence config ns²np¹⁻⁶; Groups IIIA–VIIIA.
  • s-block valence electrons = electrons in highest s orbital.
  • p-block valence electrons = electrons in highest s and p orbitals.
  • Total valence electrons = group number (A & B convention).
  • He (ns²) — technically s-block, but by chemical behaviour placed in Group VIII.
  1. d-block (transition metals): last electron enters a d-orbital; valence config ns⁰⁻²(n−1)d¹⁻¹⁰ (except palladium).
  • Total valence electrons = outermost (ns) + penultimate [(n−1)d].
  1. f-block (inner transition elements): last electron enters an f-orbital; config ns²(n−1)d⁰⁻¹(n−2)f¹⁻¹⁴.
  • Total valence electrons = ns + (n−1)d + (n−2)f.

4.3.4 The Representative (Main Group) Elements

  • Representative/main-group elements: Groups IA–VIIA, with incompletely filled s or p subshells of the highest principal quantum number.
  • Noble gases (VIIIA): completely filled p subshell (except He = 1s²; others ns²np⁶).
  • Traditional group names: Group I = alkali metals, II = alkaline earth metals, III = boron family, IV = carbon family, V = nitrogen family, VI = oxygen family, VII = halogens, VIII = noble gases.
  • Group IA: noble gas core + ns¹; Group IIA: noble gas core + ns²; halogens: ns²np⁵.
  • Same number of valence electrons → similar chemical behaviour.
  • Caution (Group IVA): same outer config (ns²np⁴), but properties vary: C = nonmetal, Si/Ge = metalloids, Sn/Pb = metals.
